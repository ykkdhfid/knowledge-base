## 第 0 章　先认识两位主角
### 0.1 Python 是什么？（大白话）
Python 是一种「编程语言」。编程语言就是用来跟电脑说话的语言——你用 Python 写一句话，电脑就照做一件事。
Python 的特点是：
-  写法接近英语，读起来像大白话，是公认最容易上手的语言之一。
-  啥都能干：写小工具、做网站、处理 Excel、搞数据分析、做 AI，样样都行。
-  全世界的程序员都在用，遇到问题网上随便一搜就有答案。
**💡 小贴士：**一句话：Python = 跟电脑说话的语言，你写，它做。
### 0.2 智能体（AI Agent）是什么？（大白话）
先看这个词：AI Agent，中文叫「智能体」。
你可以把它想象成：一个「会动脑子的机器人秘书」。
普通的机器人，你说一句它做一句；而智能体不一样——
-  它有大模型当「大脑」（会思考、会说话）
-  有工具当「手脚」（能算数、能查资料、能操作电脑）
-  有记忆当「笔记本」（记得你说过什么）
所以智能体 = 大脑 + 手脚 + 记忆，能自己琢磨着把任务完成。
**💡 小贴士：**你现在正在用的这个对话助手，就是一个智能体的例子——它有大模型大脑，也有工具（能读写文件、运行程序、上网搜索）。

## 第 1 章　跑起你的第一个 Python 程序
### 1.1 怎么运行 Python 代码
有 3 种常见方式，新手推荐第 3 种：
-  双击 .py 文件（最简单，但窗口一闪而过，看不到结果）
-  命令行：在 cmd 里输入 python 文件名.py 回车
-  用编辑工具（推荐）：装 VS Code（免费），新建文件存为 xxx.py，点右上角 ▶ 运行。
**💡 小贴士：**先把这段代码复制到一个新文件里，起名叫 hello.py，然后运行它：
**【例 1】你的第一个程序**
print("你好，世界！")
print("我叫 Python，很高兴认识你！")
**运行结果（输出）：**
你好，世界！
我叫 Python，很高兴认识你！
看到了吗？print 就是「打印、输出」的意思，括号里的内容会显示在屏幕上。就这么简单，你已经会写 Python 了！
### 1.2 代码是「从上往下」读的
电脑读你的代码，就像你读文章一样：一行一行，从上往下执行。这一点很重要，后面所有例子都靠它。
**【例 2】从上往下执行**
print("第一行先执行")
print("第二行接着执行")
print("最后执行这一行")
## 第 2 章　Python 语法速成（只学够用的）
这一章是核心。别怕，每个知识点都配了能直接运行的例子，跟着敲一遍就懂了。
### 2.1 变量：给数据贴标签
变量就是一个「标签」，把数据存起来，随时能拿出来用。
**【例 3】变量**
name = "鹿乃"    # 文字，要用引号包起来
age = 20          # 数字，不用引号
print("她叫" + name)
print("今年", age, "岁")
**运行结果（输出）：**
她叫鹿乃
今年 20 岁
**💡 小贴士：**「=」是赋值号，意思是「把右边的值存进左边的标签」。它是「等于」？不是！是「把…放进…」。
### 2.2 数据类型：数字、文字、真假
电脑里的数据主要有这几种，记住就行：

| 类型 | 名字 | 例子 | 大白话 |
| --- | --- | --- | --- |
| str | 字符串 | "你好" | 文字，必须加引号 |
| int | 整数 | 100 | 不带小数的数字 |
| float | 小数 | 3.14 | 带小数点的数字 |
| bool | 布尔 | True / False | 真或假 |
| list | 列表 | ["苹果", "香蕉"] | 一串东西，有序号 |
| dict | 字典 | {"名字": "鹿乃"} | 「名字→值」的配对 |

**【例 4】数据类型**
a = "你好"      # 字符串
b = 3.14        # 小数
c = 100         # 整数
d = True        # 布尔（真）
e = ["苹果", "香蕉", "橘子"]   # 列表
f = {"名字": "鹿乃", "职业": "歌手"}  # 字典
print(type(a))   # type 可以查看类型
print(e[0])      # 取列表第 1 个（注意：从 0 开始数！）
print(f["名字"]) # 按名字取字典的值
**运行结果（输出）：**
<class 'str'>
苹果
鹿乃
**💡 小贴士：**列表和字典的序号/名字都是「从 0 开始数」或者「按名字取」，别记反了。
### 2.3 让电脑听你的话：input 输入
**【例 5】input 输入**
name = input("请输入你的名字：")
print("你好，" + name + "！欢迎来到 Python 世界！")
**运行结果（输出）：**
请输入你的名字：小明
你好，小明！欢迎来到 Python 世界！
**💡 小贴士：**运行到 input 时程序会停下来等你打字，回车后才继续。
### 2.4 让电脑做判断：if
if 就是「如果…就…」。注意：if 下面的代码要缩进（前面空 4 个空格），这是 Python 的规矩。
**【例 6】if 判断**
score = 85
if score >= 90:
    print("优秀！")
elif score >= 60:
    print("及格了，继续加油！")
else:
    print("不及格，再努力！")
**运行结果（输出）：**
及格了，继续加油！
### 2.5 让电脑反复干活：for 和 while
**【例 7】for 循环**
for i in range(5):        # range(5) = 0,1,2,3,4
    print("第", i, "次循环")
**运行结果（输出）：**
第 0 次循环
第 1 次循环
第 2 次循环
第 3 次循环
第 4 次循环
**【例 8】while 循环**
count = 3
while count > 0:
    print("倒计时：", count)
    count = count - 1   # 每圈减 1，减到 0 就停
print("发射！")
**运行结果（输出）：**
倒计时： 3
倒计时： 2
倒计时： 1
发射！
**💡 小贴士：**for 适合「数几遍」，while 适合「直到某条件不成立」。
### 2.6 列表和字典：装东西的盒子（进阶例子）
**【例 9】列表 + for**
songs = ["アイロニ", "Stella-rium", "デビルじゃないもん"]

**运行结果（输出）：**

### 2.7 函数：把代码打包成工具
函数就是「打包好的一段代码」，起个名字，随时调用。写一次，用 N 次。
**【例 11】函数**
def 打招呼(name):
    print("你好呀，" + name + "！")

打招呼("主人")
打招呼("鹿乃")
**运行结果（输出）：**
你好呀，主人！
你好呀，鹿乃！
**💡 小贴士：**def 就是 define（定义）的缩写。函数要先用 def 定义，才能调用。
### 2.8 模块：借别人的工具箱
模块（也叫库）就是别人写好的工具箱。用 import 借来就能用，不用自己造轮子。
**【例 12】import 模块**
import random        # 随机数工具箱
print(random.randint(1, 6))    # 掷骰子：随机 1~6

import datetime      # 日期时间工具箱
print(datetime.datetime.now())
**运行结果（输出）：**
3
2026-08-16 12:00:00.123456
**💡 小贴士：**输出的数字每次都不一样，因为是随机的。import 之后用「工具箱.工具」的方式调用。
### 2.9 综合实例：猜数字游戏
把上面学到的全用上：input（输入）、if（判断）、while（循环）、import（借工具箱）。
**【例 13】猜数字游戏（综合实例）**
import random

secret = random.randint(1, 100)
print("我想到一个 1~100 的数字，你来猜！")

while True:
    guess = int(input("你猜的数字："))   # int() 把文字变成数字
    if guess > secret:
        print("太大了！")
    elif guess < secret:
        print("太小了！")
    else:
        print("恭喜你猜对了！答案就是", secret)
        break   # 跳出循环
**运行结果（输出）：**
我想到一个 1~100 的数字，你来猜！
你猜的数字：50
太大了！
你猜的数字：25
太小了！
你猜的数字：37
恭喜你猜对了！答案就是 37
试着把它改一改：把 100 改成 1000，或者加一个「猜了几次」的计数。改坏了也没关系，改错是学习的一部分！
## 第 3 章　智能体（AI Agent）：会动脑子的机器人
### 3.1 大模型是什么？（大白话）
大模型（LLM）就像一个「读完了全人类书籍的学霸」：你把问题发给它，它就能给你一段像模像样的回答。
它不会真的「思考」，但它的回答是基于海量知识训练出来的，所以看起来非常聪明。GPT、DeepSeek、文心一言……这些聊天机器人，背后都是大模型。
### 3.2 智能体 = 大脑 + 手脚 + 记忆

| 零件 | 大白话 | 例子 |
| --- | --- | --- |
| 大脑（大模型） | 负责思考和说话 | DeepSeek、GPT 这类模型 |
| 提示词 Prompt | 你给大脑下的指令 | "你是一个贴心的助手" |
| 工具 Tool | 大脑的「手脚」，能实际干活 | 算数、查天气、读文件、上网 |
| 记忆 Memory | 记得之前聊过什么 | 对话历史记录 |

普通程序：你输入 → 程序按写死的规则输出（死板）。
智能体：你输入 → 大脑理解 → 决定要不要用工具 → 组织回答 → 记住这次对话（灵活）。
### 3.3 先动手：做一个「不用联网」的迷你智能体
别急，先不碰大模型。我们用 if/else 就能做一个「机器人」——它也能听懂几句人话！
**【例 14】迷你智能体（规则版）**
import random

心情 = ["开心", "困了", "元气满满", "想唱歌"]

print("迷你智能体上线！输入 bye 结束。")
while True:
    word = input("你对小鹿说：")
    if word == "bye":
        print("小鹿：拜拜~")
        break
    elif "你好" in word:
        print("小鹿：你好呀！今天", random.choice(心情), "！")
    elif "歌" in word:
        print("小鹿：好呀，给你唱一首アイロニ～ 啦啦啦～")
    elif "累" in word:
        print("小鹿：辛苦了！快休息一下~")
    else:
        print("小鹿：嗯嗯，我听到啦！")
**运行结果（输出）：**
迷你智能体上线！输入 bye 结束。
你对小鹿说：你好
小鹿：你好呀！今天 元气满满 ！
你对小鹿说：好累
小鹿：辛苦了！快休息一下~
你对小鹿说：bye
小鹿：拜拜~

## 第 4 章　动手做你的第一个真智能体（配大模型大脑）
### 4.1 准备：申请密钥 + 装一个库
要跟大模型说话，需要两样东西：
- ①  一个 API 密钥：相当于「大模型的通行证」。以 DeepSeek 为例：去 platform.deepseek.com 注册 → 创建 API Key → 复制保存（要花钱，但很便宜，新用户一般有赠送额度）。
- ②  一个叫 openai 的库（DeepSeek 的接口和它兼容）：在 cmd 里执行 pip install openai 回车即可。
**💡 小贴士：**密钥就像密码，别发给别人。下面的代码里把「你的密钥」换成真的就行。
### 4.2 实例：第一个问答智能体（10 行代码）
**【例 15】第一个问答智能体**
# 第一次运行前先安装：pip install openai
from openai import OpenAI

# 连接大模型（这里用 DeepSeek 的接口）
client = OpenAI(api_key="你的密钥", base_url="https://api.deepseek.com")

# 问它一个问题
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)

# 把它的回答打印出来
print(resp.choices[0].message.content)
**运行结果（输出）：**
我是 DeepSeek，一个乐于助人的 AI 助手，有什么可以帮你的吗？
拆开看这 10 行：
-  OpenAI(api_key=..., base_url=...)：跟大模型「对上暗号」
-  messages=[...]：把「你说的话」发给它，role 是 "user" 表示这是用户说的
-  resp.choices[0].message.content：从回复里取出它说的话
恭喜！你的第一个真·智能体诞生了！它现在能回答任何问题——因为它有个聪明的大脑。
### 4.3 实例：带记忆的聊天机器人（能记住聊过什么）
关键：把「聊过的每一句话」都存进 messages 列表，每次都把整个聊天记录发给大模型，它就「记得」了。
**【例 16】带记忆的聊天机器人**
from openai import OpenAI

client = OpenAI(api_key="你的密钥", base_url="https://api.deepseek.com")

# 记忆：先放一条「系统设定」，告诉它它是个什么样的助手
history = [{"role": "system", "content": "你是一个说话可爱的助手，用中文回答。"}]

print("智能体已上线！输入 bye 结束对话。")
while True:
    user = input("你：")
    if user == "bye":
        print("智能体：拜拜~ 下次见！")
        break
    history.append({"role": "user", "content": user})      # 记住你说的
    resp = client.chat.completions.create(
        model="deepseek-chat",
        messages=history,
    )
    answer = resp.choices[0].message.content
    print("智能体：", answer)
    history.append({"role": "assistant", "content": answer})  # 记住它说的
**运行结果（输出）：**
智能体已上线！输入 bye 结束对话。
你：我叫小明
智能体：你好呀小明！很高兴认识你~
你：我叫什么来着？
智能体：你叫小明呀，刚才你告诉我的！
你：bye
智能体：拜拜~ 下次见！
**💡 小贴士：**三种 role：system=系统设定，user=你，assistant=它。整段历史就是它的「记忆」。
### 4.4 实例：会「用工具」的智能体（这才是 Agent 的精髓）
普通聊天只会动嘴，真正的智能体会「动手」——比如让它算一道数学题，它能调用一个计算器工具，算完再把结果组织成回答。
原理三步走：大脑说「我要用计算器」→ 程序去执行计算器 → 把结果还给大脑 → 大脑组织回答。
**【例 17】会用工具的智能体**
from openai import OpenAI
import json

client = OpenAI(api_key="你的密钥", base_url="https://api.deepseek.com")

# 第 1 步：我们给它准备一个「工具」——计算器
def 计算器(expr):
    return eval(expr)   # 计算数学表达式（教学演示用）

tools = [{
    "type": "function",
    "function": {
        "name": "计算器",
        "description": "帮用户计算数学表达式，如 23*45 或 (1+2)*3",
        "parameters": {
            "type": "object",
            "properties": {"expr": {"type": "string", "description": "数学表达式"}},
            "required": ["expr"]
        }
    }
}]

while True:
    user = input("你：")
    if user == "bye":
        break
    resp = client.chat.completions.create(
        model="deepseek-chat",
        messages=[{"role": "user", "content": user}],
        tools=tools,
    )
    msg = resp.choices[0].message
    if msg.tool_calls:   # 大脑说：我要用工具！
        tool = msg.tool_calls[0].function
        args = json.loads(tool.arguments)   # 解析参数
        result = 计算器(args["expr"])       # 执行工具
        print("🔧 智能体调用了计算器：", args["expr"], "=", result)
        # 把工具结果还给大脑，让它组织回答
        resp2 = client.chat.completions.create(
            model="deepseek-chat",
            messages=[
                {"role": "user", "content": user},
                msg,
                {"role": "tool", "tool_call_id": msg.tool_calls[0].id, "content": str(result)},
            ],
            tools=tools,
        )
        print("智能体：", resp2.choices[0].message.content)
    else:
        print("智能体：", msg.content)
**运行结果（输出）：**
你：帮我算一下 23*45 等于多少
🔧 智能体调用了计算器： 23*45 = 1035
智能体：23×45 等于 1035。
你：bye
**💡 小贴士：**「工具」就是你自己写的普通 Python 函数！想让它会查天气？写个查天气的函数，按同样的格式注册成工具就行。

## 第 5 章　新手最常遇到的报错（附解决办法）
报错不可怕！电脑报错是在帮你找问题。下面是最常见的几种：

| 报错信息 | 大白话解释 | 怎么办 |
| --- | --- | --- |
| SyntaxError | 语法错了，代码不合规矩 | 看它提示的行号，检查括号、引号、冒号是不是成对 |
| NameError: name 'x' is not defined | 用了没定义的名字 | 检查拼写，或忘了定义这个变量 |
| IndentationError | 缩进错了（该空格的没空） | if/for/def 下面的行前面加 4 个空格 |
| TypeError | 类型不对（比如把数字和文字相加） | 用 str() 转文字、int() 转数字 |
| ModuleNotFoundError | 没安装这个库 | cmd 里执行 pip install 库名 |
| ConnectionError / 超时 | 网络连不上或密钥不对 | 检查网络、API 密钥、base_url 是否填对 |

遇到没见过的报错怎么办？把报错信息复制下来，去网上搜，或者直接问 AI 助手——把它发给它，让它帮你改。
