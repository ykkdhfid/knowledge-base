这份文档是专门给「英语零基础」和「基础薄弱」的同学准备的。无论你是准备考研英语、大学英语四六级，还是单纯想把英语捡起来，只要你能读懂中文，就能跟着这本书把英语语法的骨架搭起来。

### 三、学语法的正确心态
- 语法不是「背」出来的，是「用」出来的。不要死记硬背规则条文，要理解规则背后的「为什么」，然后到例句里去体会。
- 先懂「意思」，再记「公式」。看到 I have finished my homework. 先想：这句话想表达「我已经完成作业了」这个意思；再去看 have + finished 这个公式是怎么拼出来的。意思优先，形式跟上。
- 允许自己犯错。错误是最好的老师。每次犯错，对照附录 C 查一查，错误就会越来越少。
- 耐心比聪明更重要。语法是成体系的，前期慢一点没关系，坚持三个月，你会发现自己突然「开窍」了。
**【提示】**本书默认顺序是「先时态、后其他语法」。如果你时间紧张，优先学第 3、4、5、6、9 章（考试中出现频率最高的五个时态），再学第 14 章被动语态和第 18 章定语从句。

## 第1章 英语句子的地基
盖房子要先有砖头和水泥，学英语要先认识「词性」和「句子成分」。这一章我们只做一件事：认识英语句子的零件和拼装规则。看完这一章，你会明白一个英语句子到底是怎么搭起来的。
### 1.1 词性：单词的「身份证」
每个英语单词都有自己的「身份」，我们叫它词性。词性决定了这个单词在句子里能干什么活。英语里有 10 大类词性，下面用一句话 + 一个例子说清楚：

| 词性 | 大白话解释 | 例子 |
| --- | --- | --- |
| 名词 noun | 给人、物、地方、事情取名字的词 | book 书, teacher 老师, love 爱 |
| 动词 verb | 表示「动作」或「状态」的词 | run 跑, eat 吃, is 是 |
| 形容词 adjective | 形容名词「长什么样、什么性质」 | beautiful 漂亮的, big 大的 |
| 副词 adverb | 修饰动作或形容词，说明「怎么、多快、多很」 | quickly 快速地, very 非常 |
| 代词 pronoun | 代替名词，避免重复 | I 我, you 你, he 他, it 它 |
| 介词 preposition | 表示位置、方向、时间的「小词」，后面常跟名词 | in 在…里, on 在…上, at 在…时 |
| 连词 conjunction | 把单词或句子「连起来」的词 | and 和, but 但是, because 因为 |
| 冠词 article | 放在名词前的「小帽子」，表一个或特指 | a, an, the |
| 数词 numeral | 表示「数量」或「顺序」的词 | one 一, first 第一 |
| 感叹词 interjection | 表达惊讶、高兴等情绪的词 | Oh! 哦!, Wow! 哇! |

### 1.2 句子成分：谁 + 干什么
一个完整的句子，就像一部小电影：有「主人公」，有「干的事」，还可能有个「受气包」。用「谁 + 干什么」来拆句子，是最简单的方法。先看 7 种句子成分：

| 成分 | 大白话解释 | 例子 |
| --- | --- | --- |
| 主语 | 句子的主人公，动作的发出者（谁） | I 我, The cat 那只猫 |
| 谓语 | 主人公干的事，核心是动词（干什么） | run 跑, is 是 |
| 宾语 | 动作的承受者（干到谁身上） | him 他, the book 这本书 |
| 定语 | 修饰名词的「装饰品」（什么样的） | a red apple 里的 red |
| 状语 | 说明时间、地点、方式的「背景板」 | yesterday 昨天, in the park 在公园 |
| 补语 | 补充说明主语或宾语的状态 | make me happy 里的 happy |
| 表语 | 跟在系动词后面，描述主语「是什么样」 | She is a teacher 里的 a teacher |

【拆句演示】
I love English.
谁（主语）= I 我；干什么（谓语）= love 爱；爱什么（宾语）= English 英语
She sings beautifully.
谁（主语）= She 她；干什么（谓语）= sings 唱；怎么唱（状语）= beautifully 动听地
We call him Tom.
谁 = We 我们；干什么 = call 叫；叫谁（宾语）= him 他；叫什么（宾补）= Tom 汤姆
### 1.3 五大基本句型：英语句子的五种「骨架」
不管多长的句子，拆到最后都逃不出 5 种基本骨架。这 5 种骨架就是英语句子的「乐高底座」：

| 句型 | 公式 | 例句 |
| --- | --- | --- |
| 主谓 | 主语 + 谓语（不及物动词） | Birds fly. 鸟儿飞。 |
| 主谓宾 | 主语 + 谓语 + 宾语 | I love you. 我爱你。 |
| 主谓宾宾 | 主语 + 谓语 + 间接宾语 + 直接宾语 | He gave me a book. 他给了我一本书。 |
| 主谓宾补 | 主语 + 谓语 + 宾语 + 宾补 | We call him Tom. 我们叫他汤姆。 |
| 主系表 | 主语 + 系动词 + 表语 | She is a teacher. 她是一名老师。 |

**【重点】**这 5 种骨架是句子的「主干」。以后学定语从句、状语从句，都是在主干上「加装饰」。见到长句先找主干，句子立刻就变短了。
### 1.4 句子种类：说话的语气
同一个意思，可以用不同的「语气」说出来。英语句子按语气分成 4 类：

| 种类 | 作用 | 例子 |
| --- | --- | --- |
| 陈述句 | 陈述一个事实（句号结尾） | I am a student. 我是一名学生。 |
| 疑问句 | 提出一个问题（问号结尾） | Are you a student? 你是学生吗？ |
| 祈使句 | 请求、命令、建议（常省略主语） | Please open the door. 请开门。 |
| 感叹句 | 表达强烈的感情（感叹号结尾） | What a beautiful day! 多美好的一天！ |

## 第2章 时态总览（先建框架）
### 2.1 什么是时态？时间 × 状态
「时态」这个词看着吓人，拆开就两个部分：「时」是时间（过去、现在、将来），「态」是状态（一般、进行、完成、完成进行）。两者一组合，4 个时间 × 4 个状态 = 16 种时态。
打个比方：「一般」像拍照片，定格一个动作；「进行」像录视频，记录动作正在进行的过程；「完成」像翻看相册，说明动作已经做完、对现在有影响；「完成进行」则是「从过去一直录到现在还没停」的长视频。
再换个比喻：时间是「坐标轴」，状态是「镜头的三种模式」。把动作放到坐标轴的不同位置、用不同镜头拍，就是不同的时态。
### 2.2 16 种时态一览大表
先把 16 种时态的全家福看一遍，混个脸熟。记不住没关系，后面的章节会一个一个讲：

| 时态名称 | 结构公式 | 一句话用法 | 代表标志词 |
| --- | --- | --- | --- |
| 一般现在时 | do / does；am / is / are | 习惯、真理、现状 | always, every day |
| 一般过去时 | did；was / were | 过去发生并结束 | yesterday, ago |
| 一般将来时 | will do；be going to do | 将来要发生 | tomorrow, next week |
| 过去将来时 | would do | 站在过去看将来 | the next day |
| 现在进行时 | am / is / are doing | 正在发生 | now, Look! |
| 过去进行时 | was / were doing | 过去某刻正在发生 | at 8 yesterday, while |
| 将来进行时 | will be doing | 将来某刻正在发生 | at this time tomorrow |
| 过去将来进行时 | would be doing | 过去看将来某刻正在 | the next day at 8 |
| 现在完成时 | have / has done | 已发生，影响现在 | already, since, for |
| 过去完成时 | had done | 过去的过去 | by the time, before |
| 将来完成时 | will have done | 将来某时已完成 | by next year |
| 过去将来完成时 | would have done | 过去看将来已完成 | the following year |
| 现在完成进行时 | have / has been doing | 从过去持续到现在 | since, all day |
| 过去完成进行时 | had been doing | 过去某时前一直持续 | by then, for |
| 将来完成进行时 | will have been doing | 将来某时前一直持续 | by next year |
| 过去将来完成进行时 | would have been doing | 过去看将来一直持续 | ——（极少用） |

**【提示】**前 12 种时态最重要，最后 4 种（过去将来进行时、过去将来完成时、过去将来完成进行时等）考试极少出现，看懂即可。你不需要背这张表，只需要知道「时态 = 时间 + 状态」这个框架，具体细节后面逐章展开。
### 2.3 时间轴：一条线看懂时间
把时间想象成一条从左到右的线：左边是过去，中间是现在，右边是将来。不同时态就是在线上不同的「站位」：
过去 ------------ 现在 ------------ 将来
  |                 |                 |
 一般过去时         一般现在时         一般将来时
  过去完成时 ← 站在过去更早的位置（过去的过去）
  现在完成时 ← 从过去一直连到现在的「桥」
  将来完成时 ← 站在将来回头看「已经做完」
记住：完成时的核心不是「过去」，而是「站在某个时间点回头看」。站在现在回头看就是现在完成时，站在过去回头看就是过去完成时，站在将来回头看就是将来完成时。
### 2.4 学时态的三大法宝
- 法宝一：时间状语（路标）。yesterday、tomorrow、now、since、for 这些词直接告诉你用哪个时态。看到 yesterday 用一般过去时，看到 tomorrow 用一般将来时。
- 法宝二：动词形式（钥匙）。时态最后都落实在动词怎么变上：do / did / will do / doing / done / have done……动词的形式就是时态的「身份证」。
- 法宝三：语境（法官）。没有时间状语时，就靠上下文的意思判断：这件事是习惯？正在发生？还是已经完成？语境说了算。
**【技巧】**做题时按这个顺序判断时态：① 找时间状语 → ② 看动词形式 → ③ 分析语境。三个信号都指向同一个时态，答案基本就稳了。
## 第3章 一般现在时
### 3.1 用法：什么时候用一般现在时？
一般现在时是英语里「出场率最高」的时态，一共管三件事：
- 习惯和反复发生的动作：I get up at seven every day. 我每天七点起床。
- 客观真理和自然规律：The earth goes around the sun. 地球绕太阳转。
- 现在的状态和事实：She is a teacher. 她是一名老师。
一句话记法：凡是「经常做、一直对、现在就是」的事，都用一般现在时。
### 3.2 构成公式：be 动词 vs 实义动词
一般现在时有两套班子：be 动词（am / is / are）和实义动词（like、go 这类有具体意思的动词）。注意：一个句子里只能有一个「老大」，要么用 be，要么用实义动词，绝对不能两个都用。

| 类型 | 肯定句 | 否定句 | 疑问句 |
| --- | --- | --- | --- |
| be 动词 | I am a student. | I am not a student. | Are you a student? |
| be 动词（他/她/它） | He is tall. | He is not tall. | Is he tall? |
| 实义动词（第一/二人称） | I like music. | I don't like music. | Do you like music? |
| 实义动词（第三人称单数） | He likes music. | He doesn't like music. | Does he like music? |

规律：肯定句里，三单主语（he / she / it / Tom / my father）的实义动词要加 s 或 es；否定和疑问句里，把「脏活累活」交给 do / does 去干，动词自己变回原形。
### 3.3 第三人称单数变化规则表
什么是「第三人称单数」？就是「他 / 她 / 它」以及一切能用 he、she、it 代替的人或物。主语是它们时，动词要变身：

| 规则 | 怎么变 | 例子 |
| --- | --- | --- |
| 一般情况 | 直接加 s | like → likes, play → plays, run → runs |
| 以 s / x / ch / sh / o 结尾 | 加 es | watch → watches, go → goes, do → does |
| 辅音字母 + y 结尾 | 变 y 为 i，再加 es | study → studies, fly → flies, carry → carries |
| 特殊词 | 直接换写法 | have → has |

**【易错】**三单加 s 是一般现在时最大的坑。写句子时先问自己：主语是 he/she/it 吗？是的话动词别忘了变身。
### 3.4 标志词（看到它们就用一般现在时）
always 总是    usually 通常    often 经常
sometimes 有时    never 从不    every day 每天
on Mondays 每逢周一    twice a week 每周两次
频率副词（always / usually / often / sometimes / never）的位置有讲究：放在 be 动词后面（He is always happy.），放在实义动词前面（He always gets up early.）。
### 3.5 例句（先英文，后中文）
I get up at seven every day.
我每天七点起床。
She often goes to the library on Sundays.
她经常在周日去图书馆。
The sun rises in the east.
太阳从东方升起。
My father doesn't like coffee.
我爸爸不喜欢咖啡。
Do you play basketball after school?
你放学后打篮球吗？
**【易错】**① 主语是 he / she / it 时，肯定句动词加 s/es，但否定句和疑问句里用 does，动词还原原形（He doesn't like... 而不是 He doesn't likes...）。② be 动词和实义动词不能混用，I am like music 是错的，要说 I like music。
## 第4章 一般过去时
### 4.1 用法：过去发生、现在已经结束
一般过去时管「过去某一时间发生的动作或状态」，而且这件事跟现在没关系了，说完就翻篇。就像一张旧照片：拍完了，定格了。
- 过去发生的动作：I watched a movie last night. 我昨晚看了一部电影。
- 过去的状态：He was very tired yesterday. 他昨天很累。
- 过去反复发生的习惯：When I was young, I often played in the park. 我小时候常在公园玩。
### 4.2 规则动词过去式变化规则表

| 规则 | 怎么变 | 例子 |
| --- | --- | --- |
| 一般情况 | 直接加 ed | play → played, work → worked |
| 以 e 结尾 | 直接加 d | like → liked, live → lived |
| 辅音字母 + y 结尾 | 变 y 为 i，再加 ed | study → studied, carry → carried |
| 重读闭音节（辅+元+辅） | 双写末尾辅音字母，再加 ed | stop → stopped, plan → planned |

「重读闭音节」看着吓人，其实判断方法很简单：单词是「辅音字母 + 一个元音字母 + 一个辅音字母」结尾，且重音在最后一个音节，就双写。比如 stop = s-t-o-p（t、o、p），双写 p 变成 stopped。
### 4.3 不规则动词提示
英语里有 200 多个不规则动词，它们的过去式不按规则变，只能靠记。别慌，常用的就那几十个，我们已经在附录 A 里按 ABC / ABB / AAA 三种类型整理好了 80+ 个，学完这一章顺手翻一翻附录 A 就行。
### 4.4 标志词
yesterday 昨天    last week 上周    last year 去年
two days ago 两天前    in 2020 在 2020 年
just now 刚才    the day before yesterday 前天
### 4.5 例句
I visited my grandparents last weekend.
上周末我去看望了爷爷奶奶。
She was ill yesterday.
她昨天生病了。
They played basketball two hours ago.
他们两小时前打了篮球。
He didn't come to school yesterday.
他昨天没来上学。
Did you finish your homework last night?
你昨晚完成作业了吗？
**【易错】**最大的坑：did 后面动词必须用原形！did + 原形 = 过去式。He didn't came 是错的，要说 He didn't come。另外，was / were（be 动词的过去式）和 did 也不能混用：He didn't was happy 是错的，要说 He wasn't happy 或 He didn't feel happy。
**【技巧】**was / were 怎么选：I、he、she、it 用 was；you、we、they 用 were。一句话：I was，you were。
## 第5章 一般将来时
### 5.1 用法：将来要发生的事
一般将来时管「还没发生、将来会发生的动作或状态」，相当于给未来拍一张「预想照片」。表达将来有两大主力：will 和 be going to。
### 5.2 will 与 be going to 的区别
两者都能表将来，但「临时性」和「计划性」不同：

| 对比项 | will + 动词原形 | be going to + 动词原形 |
| --- | --- | --- |
| 核心含义 | 临时决定、意愿、预测 | 事先计划好的、有迹象要发生 |
| 大白话 | 「我决定……」（当场拍板） | 「我打算……」（早就想好） |
| 例子 | The phone is ringing. I will answer it. 电话响了，我去接。 | I am going to visit Beijing next month. 我下个月打算去北京。 |
| 预测 | I think it will rain tomorrow. 我觉得明天会下雨。 | Look at the clouds! It is going to rain. 看那些云！要下雨了。 |

区别口诀：当场决定用 will，早有打算用 be going to；看天象、看迹象用 be going to。
### 5.3 构成公式表

| 类型 | 肯定句 | 否定句 | 疑问句 |
| --- | --- | --- | --- |
| will | I will go. | I won't go. | Will you go? |
| be going to | I am going to go. | I am not going to go. | Are you going to go? |
| be going to（三单） | She is going to go. | She isn't going to go. | Is she going to go? |

注意：will 后面的动词必须是原形；will not 可以缩写成 won't。be going to 前面有 am / is / are，别忘了根据主语选。
### 5.4 标志词
tomorrow 明天    next week 下周    next month 下个月
soon 很快    later 稍后    in the future 将来
this weekend 这个周末    in three days 三天后
### 5.5 其他表示将来的表达
- be to do（计划、安排，较正式）：The meeting is to start at 9. 会议定于 9 点开始。
- 现在进行时表将来（位移动词）：We are leaving tomorrow. 我们明天出发。（详见第 6 章）
- 一般现在时表将来（时刻表）：The train leaves at 8. 火车 8 点开。（主将从现见第 19 章）
### 5.6 例句
I will call you later.
我晚点给你打电话。
She is going to study abroad next year.
她打算明年出国留学。
There will be a meeting tomorrow morning.
明天上午将有一个会议。
We won't have class on Friday.
我们周五不上课。
Will you come to my birthday party?
你会来我的生日聚会吗？
**【易错】**① there be 句型的将来时是 there will be 或 there is going to be，绝不能说 there will have。② will / be going to 后面跟动词原形，不能跟过去式。③ be going to 里的 be 不能丢：I going to go 是错的，要说 I am going to go。
## 第6章 现在进行时
### 6.1 用法：正在进行的「录像」
现在进行时就是「正在发生的动作」，相当于给动作现场录像。它管三件事：
- 正在发生：I am reading a book now. 我现在正在读书。
- 暂时状态（这段时间在做，不一定此刻）：She is working in Shanghai these days. 她这些天在上海工作。
- 计划中的将来（位移动词）：We are flying to Beijing tomorrow. 我们明天飞往北京。
### 6.2 构成公式
肯定句：主语 + am / is / are + 动词ing
否定句：主语 + am / is / are + not + 动词ing
疑问句：Am / Is / Are + 主语 + 动词ing + ?
例：She is cooking dinner. / She is not cooking. / Is she cooking?
be 动词（am / is / are）的选择：I 用 am，he / she / it 用 is，you / we / they 用 are。
### 6.3 动词 ing 变化规则表

| 规则 | 怎么变 | 例子 |
| --- | --- | --- |
| 一般情况 | 直接加 ing | play → playing, read → reading |
| 以不发音的 e 结尾 | 去 e 再加 ing | make → making, write → writing |
| 重读闭音节（辅+元+辅） | 双写末尾辅音字母再加 ing | run → running, swim → swimming, sit → sitting |
| 以 ie 结尾 | 变 ie 为 y 再加 ing | lie → lying, die → dying, tie → tying |

### 6.4 标志词
now 现在    right now 立刻、现在    at the moment 此刻
Look! 看！    Listen! 听！
these days 这些天    this week 这周
Look! 和 Listen! 也是信号词：看见它们，后面多半是正在发生的事，要用现在进行时。
### 6.5 不能用于进行时的动词（状态动词）
有些动词天生「静态」，表示心理、感觉、拥有的状态，不能用进行时。就像一个人不可能「正在拥有」一辆车：

| 类别 | 动词（不能用进行时） |
| --- | --- |
| 心理状态 | know 知道, believe 相信, understand 明白, remember 记得, forget 忘记, think 认为 |
| 情感喜好 | like 喜欢, love 爱, hate 讨厌, want 想要, need 需要, prefer 更喜欢 |
| 感官感觉 | hear 听见, see 看见, smell 闻到, taste 尝到, feel 感觉 |
| 所属存在 | have 有, own 拥有, belong 属于, seem 似乎, look 看起来 |

**【易错】**见到这些词，就算句子有 now 也不用进行时。比如：I know him now.（对），I am knowing him now.（错）。但是 have 表示「吃、开会、玩得开心」等动作意思时可以用于进行时：We are having dinner. 我们正在吃晚饭。
### 6.6 例句
I am writing an email now.
我现在正在写邮件。
Look! The children are playing in the park.
看！孩子们正在公园里玩。
She is staying with her aunt these days.
她这些天住在姑妈家。
We are leaving for Shanghai tomorrow.
我们明天动身去上海。
Listen! Someone is singing in the classroom.
听！有人在教室里唱歌。
**【易错】**① am / is / are 千万别漏，动词的 ing 也别忘：I reading 是错的，要说 I am reading。② 状态动词不用进行时。③ 进行时表将来只用于 come、go、leave、arrive、fly、start 等「移动、出发」类动词。
## 第7章 过去进行时
### 7.1 用法：过去某时刻正在发生
过去进行时 = 站在过去某个时间点，「回放录像」。它表示过去某一时刻或某段时间正在进行的动作，也常用来给故事搭「背景」：
- 过去某刻正在发生：I was watching TV at 8 o'clock yesterday. 昨天 8 点我正在看电视。
- 背景动作（长动作）：While I was sleeping, the phone rang. 我睡觉的时候，电话响了。
### 7.2 构成公式
肯定句：主语 + was / were + 动词ing
否定句：主语 + was / were + not + 动词ing
疑问句：Was / Were + 主语 + 动词ing + ?
例：She was reading. / They were playing. / Were you sleeping?
was 用于 I / he / she / it；were 用于 you / we / they。
### 7.3 与一般过去时对比：长动作 vs 短动作
一个动作「正在进行、还没做完」用过去进行时（长动作）；一个动作「干脆利落地发生了一下」用一般过去时（短动作）。长动作是背景，短动作是插曲：

| 场景 | 长动作（过去进行时） | 短动作（一般过去时） | 中文意思 |
| --- | --- | --- | --- |
| when + 短动作打断 | I was reading | when the light went out. | 我正在读书，突然灯灭了。 |
| while + 长动作持续 | While I was cooking, | my mother came home. | 我做饭时，妈妈回家了。 |
| 两个动作同时进行 | While he was studying, | I was listening to music. | 他学习时，我在听音乐。 |

规律：when 后面常跟「短动作」（一般过去时）；while 后面常跟「长动作」（过去进行时）。口诀：when 后短，while 后长。
### 7.4 标志词
at 8 o'clock yesterday 昨天 8 点    at that time 那时
at this time yesterday 昨天这个时候
while 当……的时候    when 当……的时候
the whole morning 整个上午
### 7.5 例句
I was doing my homework at 9 last night.
昨晚 9 点我正在写作业。
She was cooking while the children were playing.
孩子们在玩的时候，她在做饭。
When I got home, my dog was waiting at the door.
我到家时，我的狗正在门口等着。
They were not watching TV at that time.
那时他们没在看电视。
Was it raining when you left?
你离开的时候在下雨吗？
**【易错】**① was / were 不能漏，ing 不能忘：I watching TV 是错的。② when 后面是短动作用一般过去时，别两个都用进行时（I was reading when the phone was ringing 不如 I was reading when the phone rang 自然）。③ 状态动词（know、like 等）同样不能用过去进行时。
## 第8章 将来进行时
### 8.1 用法：将来某时刻正在发生
将来进行时 = 站在将来某个时间点，「提前打开录像机」。它表示将来某一时刻正在进行的动作，也常用来表示「按计划一定会发生的安排」，语气比 will do 更自然、更确定。
大白话：现在的你说「明天的这个时候，我正在飞机上呢」，就是在用将来进行时。
### 8.2 构成公式
肯定句：主语 + will be + 动词ing
否定句：主语 + will not be + 动词ing
疑问句：Will + 主语 + be + 动词ing + ?
例：I will be flying to Beijing this time tomorrow.
### 8.3 标志词
this time tomorrow 明天这个时候
at 9 o'clock tomorrow morning 明天上午 9 点
at this time next week 下周这个时候
### 8.4 例句
This time tomorrow, I will be flying to Beijing.
明天这个时候，我将正飞往北京。
At 8 tomorrow morning, we will be having class.
明天早上 8 点，我们将在上课。
Don't call me at 10; I will be sleeping.
10 点别给我打电话，我那时正在睡觉。
She will be working in the lab next month.
下个月她将在实验室工作。
**【易错】**① 结构是 will be + doing，be 和 doing 都不能少：I will flying 是错的。② 别把 will be doing 和 will do 混用：will do 强调「将要做」，will be doing 强调「将来某刻正在做」。③ 一般疑问句把 will 提到句首即可。
## 第9章 现在完成时（难点）
现在完成时是公认的「难点之王」，但它的逻辑其实很简单：站在「现在」，回头看看过去发生的事对现在的影响。它是一座「连接过去和现在的桥」。
### 9.1 三种核心用法
- 用法一（过去发生，影响现在）：I have lost my key. 我把钥匙丢了。（现在进不了门）
- 用法二（从过去持续到现在）：She has lived here for ten years. 她在这里住了十年。（现在还住着）
- 用法三（过去的经历）：Have you ever been to Beijing? 你去过北京吗？（有没有这个经历）
### 9.2 构成公式
肯定句：主语 + have / has + 过去分词(done)
否定句：主语 + have / has + not + 过去分词
疑问句：Have / Has + 主语 + 过去分词 + ?
例：I have finished my homework. / He has gone home.
### 9.3 标志词
already 已经    yet 已经、还没    just 刚刚
ever 曾经    never 从不    since 自从
for + 一段时间    so far 到目前为止    recently 最近
up to now 到现在为止    in the past few years 在过去的几年里
注意 already 用在肯定句（I have already finished.），yet 用在否定和疑问句（Have you finished yet? / I haven't finished yet.）。
### 9.4 since 与 for 的区别

| 词 | 后面跟什么 | 例子 |
| --- | --- | --- |
| since | 时间点（过去的一个时刻）或过去时从句 | since 2020 自从 2020 年；since I came here 自从我来这儿 |
| for | 时间段（持续了多久） | for two years 两年了；for a long time 很久了 |

She has studied English since 2018.
她从 2018 年起学英语。（时间点）
She has studied English for seven years.
她学英语七年了。（时间段）
### 9.5 短暂动词与延续动词
有些动词的动作「嗖」一下就完了，叫短暂动词（buy、leave、die、join、borrow）；有些动作能持续，叫延续动词（live、work、stay、keep）。短暂动词不能直接和 for / since（一段时间）连用，要换成延续性表达：

| 短暂动词 | 换成延续表达 | 例句 |
| --- | --- | --- |
| buy 买 | have 拥有 | I have had this bike for two years. 这辆自行车我买了两年了。 |
| leave 离开 | be away | He has been away for a week. 他离开一周了。 |
| borrow 借入 | keep 保管 | I have kept the book for a month. 这本书我借了一个月了。 |
| die 去世 | be dead | The old man has been dead for five years. 老人去世五年了。 |
| join 加入 | be in / be a member of | She has been in the club for a year. 她加入俱乐部一年了。 |

### 9.6 have been to 与 have gone to 的区别

| 结构 | 意思 | 例子 |
| --- | --- | --- |
| have / has been to | 去过某地（人已回来） | I have been to Shanghai. 我去过上海。（现在不在上海） |
| have / has gone to | 去了某地（人还没回来） | He has gone to Shanghai. 他去上海了。（人不在说话现场） |

### 9.7 例句
I have just finished my homework.
我刚刚写完作业。
She has never been late for class.
她上课从不迟到。
They have lived here since 2015.
他们从 2015 年起就住在这里。
Have you ever seen this movie?
你以前看过这部电影吗？
He has gone to the library, so he is not here now.
他去图书馆了，所以他现在不在这儿。
### 9.8 易错点（三个大坑）
**【易错】**坑一：现在完成时不能和表示「过去具体时间」的词（yesterday、last week、in 2020、three days ago）连用。I have finished it yesterday 是错的，要说 I finished it yesterday 或 I have already finished it。
**【易错】**坑二：since 后面跟时间点或过去时从句，for 后面跟时间段，二者不能互换。I have lived here since two years 是错的，要说 for two years。
**【易错】**坑三：短暂动词不能和 for / since 直接连用，必须换成延续性表达（buy → have，leave → be away）。He has bought the bike for two years 是错的，要说 He has had the bike for two years。
## 第10章 过去完成时
### 10.1 用法：过去的过去
过去完成时表示「在过去的某个时间点之前，已经发生的动作」。它需要一个「过去参照点」：站在过去，回头看更早的事。就像电影里的闪回镜头。
大白话：两件过去的事，先发生的那件用过去完成时（had done），后发生的那件用一般过去时（did）。
### 10.2 构成公式
肯定句：主语 + had + 过去分词
否定句：主语 + had not + 过去分词
疑问句：Had + 主语 + 过去分词 + ?
例：When I arrived, the train had already left.
我到达时，火车已经开走了。
had 不分人称，I / you / he / she / it / we / they 后面都用 had，非常好记。
### 10.3 与现在完成时的区别

| 对比项 | 现在完成时 | 过去完成时 |
| --- | --- | --- |
| 参照点 | 站在现在回头看 | 站在过去的某个点回头看 |
| 公式 | have / has done | had done |
| 例子 | I have finished the book.（现在已完成） | I had finished the book before dinner.（晚饭前就完成了，参照点是过去） |

### 10.4 标志词
by the time 到……的时候    by then 到那时
by the end of last year 到去年年底为止
before 在……之前    after 在……之后
already 已经    when 当……时（配合过去时）
### 10.5 例句
By the time I got to the station, the bus had left.
我到车站时，公交车已经开走了。
She said she had seen the film before.
她说她以前看过这部电影。
After he had finished his homework, he went to bed.
他写完作业之后就去睡觉了。
They had lived in London for five years before they moved here.
他们搬来之前，在伦敦住了五年。
Had you ever been to Japan before 2020?
2020 年之前你去过日本吗？
**【易错】**① 用过去完成时必须有「过去的参照点」，不能光秃秃地单用（除非上下文交代了）。② 时间顺序别搞反：先发生的用 had done，后发生的用 did。③ by the time 后面的从句常用一般过去时，主句用过去完成时。
## 第11章 将来完成时
### 11.1 用法：将来某时已完成
将来完成时 = 站在将来的某个时间点，回头看「到那时已经做完的事」。想象你站在明年元旦，回头数这一年完成的事情，用的就是将来完成时。
### 11.2 构成公式
肯定句：主语 + will have + 过去分词
否定句：主语 + will not have + 过去分词
疑问句：Will + 主语 + have + 过去分词 + ?
例：By next year, I will have graduated from college.
到明年，我就大学毕业了。
### 11.3 标志词
by next year 到明年    by the end of this month 到这个月底
by the time + 从句 到……的时候    by 2030 到 2030 年
### 11.4 例句
By the end of this month, we will have finished the project.
到这个月底，我们将完成这个项目。
She will have saved enough money by next summer.
到明年夏天，她就能攒够钱了。
By the time you come back, I will have cooked dinner.
等你回来的时候，我就做好晚饭了。
Will you have read the whole book by Friday?
到周五你能读完这本书吗？
**【易错】**① 结构是 will have + 过去分词，have 不能少：I will finished 是错的。② 它和将来进行时的区别：will be doing 强调「正在做」，will have done 强调「已经做完」。③ 常与 by 引导的时间状语连用，答题时看到 by + 将来时间，优先想到将来完成时。
## 第12章 完成进行时（现在/过去/将来）
### 12.1 三种完成进行时一览
完成进行时 = 完成时 + 进行时的合体：既强调「持续到现在（或过去某时、将来某时）」，又强调「还在进行中」。它比完成时多了一层「过程感」：

| 时态 | 构成公式 | 意思 |
| --- | --- | --- |
| 现在完成进行时 | have / has been doing | 从过去一直做到现在，还在做 |
| 过去完成进行时 | had been doing | 到过去某时为止一直在做 |
| 将来完成进行时 | will have been doing | 到将来某时为止将一直在做 |

I have been learning English for three hours.
我已经连续学英语三个小时了。（现在还在学）
He had been working all night before he slept.
他睡觉之前已经连续工作了一整夜。
By next year, she will have been teaching for ten years.
到明年，她教书就满十年了。
### 12.2 与完成时的区别

| 对比项 | 完成时（have done） | 完成进行时（have been doing） |
| --- | --- | --- |
| 强调重点 | 结果：做完了没有 | 过程：做了多久、还在不在做 |
| 例子1 | I have written three letters. 我写了三封信。（结果：写完了） | I have been writing letters. 我一直在写信。（过程：还没写完） |
| 例子2 | She has lived here for 10 years. 她住这儿 10 年了。（事实） | It has been raining all day. 雨下了一整天。（强调持续） |

**【易错】**① 完成进行时的公式是 have / has / had / will have + been + doing，中间的 been 千万不能漏：I have doing 是错的，要说 I have been doing。② 状态动词（know、like、want 等）不用完成进行时，只用完成时。③ 表示「做完、结果」时用完成时，表示「一直在做、过程」时用完成进行时。
## 第13章 过去将来时
### 13.1 用法：站在过去看将来
过去将来时 = 「站在过去的某个时间点，说当时看来还没发生的事」。它最常出现在宾语从句里：主句用过去时（said、thought、told），从句里「将要发生」的事就用过去将来时。
大白话：昨天的你说「明天我要去北京」，用英语转述成「他说他第二天要去北京」，句子里那个「要去」就是过去将来时。
### 13.2 构成公式
would + 动词原形    （= will 的过去式，临时决定）
was / were going to + 动词原形    （= be going to 的过去式，计划好的）
was / were to + 动词原形    （= be to 的过去式，正式安排）
例：He said he would come the next day.
他说他第二天会来。
### 13.3 宾语从句中的用法
主句是过去时（said / told / thought / hoped），从句表将来时，一律把 will 变成 would、把 be going to 变成 was / were going to：

| 主句（过去时） | 从句（过去将来时） | 中文 |
| --- | --- | --- |
| He said | he would come back soon. | 他说他很快会回来。 |
| She told me | she was going to buy a car. | 她告诉我她打算买辆车。 |
| I thought | it would rain that day. | 我以为那天会下雨。 |

注意：从句里 tomorrow 要变成 the next day（第二天）、now 要变成 then（那时），这是「时态呼应」的一部分。
### 13.4 例句
He said he would help me with my English.
他说他会帮我学英语。
We knew they were going to hold a party.
我们知道他们打算举办一个聚会。
She hoped she would pass the exam.
她希望她能通过考试。
They said they would visit us the following week.
他们说他们第二周会来看我们。
**【易错】**① 过去将来时几乎不单独使用，必须出现在「过去时的语境」里（主句过去时、或明确的时间背景）。② would 后动词用原形。③ 别把 would 当成 will 的随意替换：只有在过去的语境里谈「将来的事」才用 would。
## 第14章 被动语态
### 14.1 什么是被动？主动 vs 被动
一句话区分：「我打他」是主动（我出手），「他被打」是被动（他挨打）。主动句强调「谁干的」，被动句强调「谁被怎么样了」。
主动：I beat him. 我打他。（主语 I 是动作发出者）
被动：He was beaten (by me). 他（被我）打了。（主语 He 是动作承受者）
把主动句变成被动句，就像「换主角」：动作的承受者升为主角（主语），动作的发出者退居幕后（by + 宾语）。
### 14.2 构成公式：be + 过去分词
被动语态 = be（随主语和时态变化）+ 过去分词(done)
例：The house was built in 2000.
这座房子建于 2000 年。
be 动词要跟着「时态」和「主语」变：was / were（过去）、is / are（现在）、will be（将来）、has been（完成）、is being（进行）……所以学被动语态 = 学会给 be 换衣服。
### 14.3 各时态被动语态公式表

| 时态 | 被动公式 | 例句 |
| --- | --- | --- |
| 一般现在时 | am / is / are + done | English is spoken in many countries. |
| 一般过去时 | was / were + done | The bridge was built in 1990. |
| 一般将来时 | will be + done | The meeting will be held tomorrow. |
| 过去将来时 | would be + done | He said the work would be finished. |
| 现在进行时 | am / is / are + being + done | The road is being repaired now. |
| 过去进行时 | was / were + being + done | The car was being washed at 8. |
| 现在完成时 | have / has + been + done | The task has been completed. |
| 过去完成时 | had + been + done | The letter had been sent before he came. |
| 将来完成时 | will + have + been + done | The project will have been finished by May. |
| 情态动词 | can / must / should + be + done | This book can be borrowed from the library. |

### 14.4 主动变被动三步法
三步走，主动句秒变被动句：
- 第一步：把主动句的宾语提到前面当新主语（I beat him → him 变成主语）。
- 第二步：谓语动词变成 be + 过去分词，be 的时态和原谓语保持一致（beat 一般过去 → was beaten）。
- 第三步：把原来的主语放到 by 后面（by me），如果没必要说「谁干的」可以省略。
主动：They  built   the house  in 2000.
      主语     谓语     宾语
被动：The house  was built  (by them)  in 2000.
      新主语     be+过去分词     by+原主语
### 14.5 被动语态的使用时机
- 不知道动作是谁干的：My bike was stolen. 我的自行车被偷了。（不知道谁偷的）
- 不关心谁干的，关心动作本身：Rice is grown in the south. 南方种水稻。
- 想突出承受者：The hero was remembered by everyone. 这位英雄被所有人铭记。
- 说话更礼貌、客观：It is said that... 据说……
### 14.6 get 被动
口语里常用 get + 过去分词表示被动，特别强调「自己遭遇了什么」：
get married 结婚    get hurt 受伤    get dressed 穿好衣服
get lost 迷路    get paid 领工资
例：He got hurt in the accident. 他在事故中受伤了。
### 14.7 易错点
**【易错】**① 不及物动词（happen 发生、appear 出现、die 去世、arrive 到达）没有被动语态：The accident was happened 是错的，要说 The accident happened。
**【易错】**② 双宾语句（give sb sth）变被动有两种方式：He gave me a book → I was given a book（间接宾语作主语）或 A book was given to me（直接宾语作主语，别忘了加介词）。
**【易错】**③ 感官动词 see / hear sb do 变被动时，动词不定式要加 to：I saw him run → He was seen to run。④ 被动句里的 be 不能丢：The house built in 2000 是错的（built 单独出现是过去分词，没有 be 就没有被动）。
## 第15章 情态动词
### 15.1 什么是情态动词
情态动词是「有情绪的动词帮手」：它们自己不干实事，而是给后面的动词加上「能、可以、必须、应该、可能」等语气。情态动词后面必须跟动词原形。
情态动词 + 动词原形
例：I can swim. 我会游泳。    You must go now. 你现在必须走了。
### 15.2 常用情态动词用法表

| 情态动词 | 含义与用法 | 肯定例句 | 否定形式 |
| --- | --- | --- | --- |
| can / could | 能、会（能力）；可以（许可）；could 更委婉 | I can speak English. 我会说英语。 | can't / couldn't |
| may / might | 可以（许可）；可能（推测）；might 更不确定 | May I come in? 我可以进来吗？ | may not / might not |
| must | 必须（主观义务）；一定是（推测） | You must finish it today. 你必须今天完成。 | mustn't 禁止（千万别） |
| have to | 不得不（客观需要），有人称和时态变化 | I have to get up early. 我不得不早起。 | don't have to 不必 |
| should | 应该（建议、义务） | You should see a doctor. 你应该看医生。 | shouldn't |
| ought to | 应该（比 should 语气稍强） | You ought to apologize. 你应该道歉。 | ought not to |
| need | 需要；否定表「不必」 | You need to rest. 你需要休息。 | needn't 不必 |
| dare | 敢（多用于否定和疑问） | How dare you say that! 你竟敢这么说！ | dare not |
| will / would | 将；愿意；would 更委婉 | I will help you. 我会帮你。 | won't / wouldn't |
| shall | 将（第一人称）；征求意见 | Shall we go? 我们走吧？ | shan't 极少用 |

### 15.3 情态动词表推测
情态动词还可以用来「猜」事情的可能性，按确信程度排序：

| 确信程度 | 表达 | 例子 | 中文 |
| --- | --- | --- | --- |
| 几乎肯定（肯定） | must be | He must be tired. 他一定累了。 | 一定 |
| 很可能 | should be | She should be home now. 她现在应该在家。 | 应该 |
| 有可能 | may / might / could be | It may rain tomorrow. 明天可能下雨。 | 可能 |
| 几乎肯定（否定） | can't be | It can't be true. 这不可能是真的。 | 不可能 |

**【易错】**表推测时：肯定句用 must（一定）、may / might（可能）；否定句用 can't（不可能），绝不能用 mustn't 表推测。He mustn't be at home（错，mustn't 是「禁止」）要说 He can't be at home（他不可能在家）。
**【易错】**① 情态动词后跟动词原形，不能跟 to（have to、ought to 除外）。② must 的否定不是 mustn't（那是「禁止」），而是 needn't 或 don't have to（不必）。③ 情态动词没有人称变化：He can swim，不是 He cans swim。
## 第16章 非谓语动词
### 16.1 什么是非谓语动词
一个句子里，谓语动词只有一个（「老大」），其他动词就得「降级」变成非谓语动词：不定式（to do）、动名词（doing）、分词（doing / done）。它们不能单独作谓语，但可以当宾语、主语、定语、状语等。
大白话：一山不容二虎，第二个动词要「卸下谓语的身份」，变成 to do、doing 或 done 的样子。
### 16.2 不定式：to do
- 作宾语：I want to sleep. 我想睡觉。（want 后接 to do）
- 作目的状语：He studies hard to pass the exam. 他努力学习为了通过考试。
- 作主语：To learn English well takes time. 学好英语需要时间。（也可用 It takes time to learn English well.）
### 16.3 动名词：doing
- 作主语：Reading is my hobby. 阅读是我的爱好。
- 作宾语（enjoy / finish / avoid / mind / practice 等后接 doing）：She enjoys dancing. 她喜欢跳舞。
只接 doing 的常见动词：
enjoy 喜欢  finish 完成  avoid 避免  mind 介意
practice 练习  keep 保持  suggest 建议  miss 错过
例：Would you mind opening the window? 你介意开窗吗？
### 16.4 分词：现在分词 doing / 过去分词 done
- 作定语（修饰名词）：a running boy 一个奔跑的男孩（主动进行）；a broken cup 一个摔碎的杯子（被动完成）。
- 作状语（修饰整个句子）：Hearing the news, she cried. 听到这个消息，她哭了。（主动）Seen from the hill, the city looks beautiful. 从山上望去，城市很美。（被动）
选择 doing 还是 done，看名词和动词的关系：名词「主动发出」用 doing，名词「被动承受」用 done。
### 16.5 非谓语三大区别表

| 形式 | 时间与语态 | 例子 |
| --- | --- | --- |
| to do | 表将来、目的 | I have a lot of work to do. 我有很多工作要做。（还没做） |
| doing | 表主动、进行 | The man standing there is my teacher. 站在那儿的人是我老师。（主动站着） |
| done | 表被动、完成 | The letter written in English is from Tom. 用英语写的那封信是汤姆寄的。（信被写） |

### 16.6 易错点：forget / remember / stop 后的 to do 与 doing

| 动词 | to do（还没做） | doing（已经做过） |
| --- | --- | --- |
| forget | forget to do 忘记去做 | forget doing 忘记做过 |
| remember | remember to do 记得去做 | remember doing 记得做过 |
| stop | stop to do 停下来去做另一件事 | stop doing 停止正在做的事 |
| try | try to do 努力去做 | try doing 尝试做做看 |

I forgot to lock the door. 我忘了锁门。（门没锁）
I forgot locking the door. 我忘了（我）锁过门。（门锁了，但忘了这回事）
He stopped to smoke. 他停下来去抽烟。
He stopped smoking. 他戒烟了 / 停止抽烟。
**【易错】**口诀：to do 是「没做」的未来动作，doing 是「已做」的过去动作。另外注意：want、decide、hope、plan、agree、refuse 后面只接 to do；enjoy、finish、avoid、mind、practice、suggest 后面只接 doing，别记混。
## 第17章 名词性从句
### 17.1 什么是名词性从句
名词能在句子里当主语、宾语、表语、同位语。把一个完整的句子「打包」当成一个名词来用，这个「句子包」就是名词性从句。它有四种：主语从句、宾语从句、表语从句、同位语从句。
名词：I know the fact. 我知道这个事实。
从句：I know that he is honest. 我知道他是诚实的。
（that he is honest 整个打包，充当 know 的宾语）
### 17.2 宾语从句
宾语从句是考试重点，注意三点：引导词、陈述语序、时态呼应。
- 引导词：陈述句用 that（可省略）；一般疑问句用 if / whether（是否）；特殊疑问句用原来的疑问词（what、where、when 等）。
- 陈述语序：从句永远是「主语 + 谓语」的顺序，不能倒装。
- 时态呼应：主句过去时，从句也变成相应的过去时（一般现在→一般过去，一般将来→过去将来）。
I think (that) he is right. 我认为他是对的。
I wonder if / whether he will come. 我想知道他是否会来。
Do you know where she lives? 你知道她住在哪里吗？
【错】Do you know where does she live?（疑问词后不能再倒装）
【对】Do you know where she lives?
### 17.3 主语从句 / 表语从句 / 同位语从句
- 主语从句（从句当主语）：What he said is true. 他说的是真的。
- 表语从句（从句当表语，跟在 be 后面）：The reason is that he was ill. 原因是他生病了。
- 同位语从句（解释说明前面的抽象名词）：The news that we won made us happy. 我们赢了的消息让我们很高兴。
### 17.4 that 能否省略规则表

| 从句类型 | that 能否省略 | 例子 |
| --- | --- | --- |
| 宾语从句（单个） | 可以省略 | I know (that) he is busy. |
| 宾语从句（并列两个以上） | 第一个可省，后面不能省 | He said (that) he was ill and that he would rest. |
| 主语从句 | 不能省略 | That he passed the exam is true.（that 不能省） |
| 表语从句 | 不能省略 | The fact is that we have no time. |
| 同位语从句 | 不能省略 | The idea that we should act is right. |

**【易错】**① 宾语从句必须用陈述语序，疑问词后面的 be / 助动词不能提前。② 主句是过去时时，从句时态要「跟着倒退一格」；但如果从句说的是客观真理，仍用一般现在时：He said the earth goes around the sun. ③ whether 和 if 都能表「是否」，但介词后、句首只能用 whether。
## 第18章 定语从句
### 18.1 什么是定语从句
定语是修饰名词的「装饰品」：a beautiful girl 里 beautiful 是定语。如果装饰品是一个完整的句子，这个句子就是定语从句。被修饰的名词叫「先行词」，连接先行词和从句的词叫「关系词」。
先行词 + 关系词 + 从句
The girl who is singing is my sister.
那个正在唱歌的女孩是我姐姐。
（girl 是先行词，who 是关系词，who is singing 修饰 girl）
### 18.2 关系代词与关系副词用法表

| 关系词 | 指代 | 在从句中充当 | 例子 |
| --- | --- | --- | --- |
| who | 人 | 主语 | The man who called you left. 给你打电话的那个人走了。 |
| whom | 人 | 宾语 | The girl whom I met is nice. 我遇见的那个女孩人很好。 |
| whose | 人/物 | 定语（谁的） | The boy whose father is a doctor is my friend. 那个爸爸是医生的男孩是我朋友。 |
| which | 物 | 主语/宾语 | The book which is on the desk is mine. 桌上的那本书是我的。 |
| that | 人/物 | 主语/宾语 | The house that we bought is big. 我们买的房子很大。 |
| when | 时间 | 时间状语 | I still remember the day when we met. 我仍记得我们相遇的那天。 |
| where | 地点 | 地点状语 | This is the school where I studied. 这是我上过学的学校。 |
| why | 原因 | 原因状语 | That is the reason why he left. 那就是他离开的原因。 |

### 18.3 选择规则：看先行词
选哪个关系词，先看先行词是「人、物、时间、地点、原因」，再看它在从句里干什么活：
- 先行词是人 → who / whom / that；是物 → which / that。
- 先行词是时间 → when；是地点 → where；是原因（reason）→ why。
- 关系词在从句里作主语或宾语 → 用关系代词（who / which / that）；作状语 → 用关系副词（when / where / why）。
### 18.4 限制性 vs 非限制性定语从句

| 对比项 | 限制性定语从句 | 非限制性定语从句 |
| --- | --- | --- |
| 作用 | 必不可少，去掉意思不完整 | 补充说明，去掉主句意思仍完整 |
| 标点 | 不用逗号 | 用逗号隔开 |
| 关系词 | 可用 that | 不能用 that，只能用 who / which 等 |
| 例子 | The students who study hard pass. 用功的学生能通过。（只指用功的那部分） | My brother, who lives in Beijing, is a doctor. 我哥哥是医生，他住在北京。（补充信息） |

### 18.5 介词 + 关系代词
当关系词在从句中作介词的宾语时，介词可以提前到关系词前面：
The house in which he lives is old.
= The house which he lives in is old.
= The house that he lives in is old.
他住的那栋房子很旧。
### 18.6 易错点
**【易错】**① that 与 which 的区别：which 只能指物，that 可指人也可指物；非限制性定语从句和介词后面不能用 that。② 只能用 that 的四种情况：先行词是不定代词（all、everything、nothing、something）；先行词被最高级或序数词修饰（the best、the first）；先行词既有人又有物；先行词被 the only / the very 修饰。
**【易错】**③ 关系代词在从句中作宾语时可以省略：The book (that / which) I bought is interesting. ④ 定语从句中不能再出现代词或名词重复指代先行词：This is the book that I bought it yesterday 是错的，要去掉 it。
## 第19章 状语从句
### 19.1 什么是状语从句
状语是说明「时间、条件、原因、结果」等的背景信息。用一个完整的句子当状语，就是状语从句。状语从句像「剧场的布景」，交代主句这件事发生在什么背景下。
### 19.2 八类状语从句：引导词 + 例句

| 类型 | 常用引导词 | 例句 |
| --- | --- | --- |
| 时间 | when, while, as, until, before, after, since, as soon as | I will call you as soon as I arrive. 我一到就给你打电话。 |
| 条件 | if, unless, as long as, in case | You will fail unless you work hard. 你不努力就会失败。 |
| 原因 | because, since, as | He didn't come because he was ill. 他没来，因为他病了。 |
| 让步 | although, though, even if, even though | Although it rained, we went out. 尽管下雨了，我们还是出去了。 |
| 目的 | so that, in order that | Speak loudly so that everyone can hear. 说大声点，好让每个人都能听见。 |
| 结果 | so...that, such...that | He ran so fast that we couldn't catch him. 他跑得太快，我们追不上。 |
| 方式 | as, as if, as though | He talks as if he knew everything. 他说起话来好像什么都懂。 |
| 比较 | than, as...as, not so...as | She is taller than I am. 她比我高。 |

### 19.3 主将从现规则
这是考试高频考点：主句用一般将来时，时间状语从句和条件状语从句里「将来的事」要用一般现在时表示（主将从现）。
【主将从现】
If it rains tomorrow, we will stay at home.
如果明天下雨，我们就待在家。（从句用 rains，不用 will rain）
When I grow up, I will be a teacher.
我长大后要当老师。（从句用 grow up）
As soon as he comes back, I will tell him.
他一回来我就告诉他。（从句用 comes）
**【易错】**① 主将从现只适用于时间、条件状语从句（if、when、as soon as、until、before、after、unless），宾语从句不适用：I don't know if it will rain tomorrow.（宾语从句用 will）② because 与 so 不能同时用；although / though 与 but 不能同时用，一个句子只能有一个「连接老大」。③ so...that 中间用形容词/副词，such...that 中间用名词：so hot that / such a hot day that。
## 第20章 虚拟语气
### 20.1 什么是虚拟语气
虚拟语气用来表达「和事实相反」的假设、愿望或建议。它说的都是「假的」：如果我是你（但你不是我）、要是我当时努力了（但没努力）。记住一个原则：虚拟语气里，时间要「倒退一格」。
### 20.2 if 条件句三大类公式表

| 假设的情况 | if 从句（条件） | 主句（结果） | 例句 |
| --- | --- | --- | --- |
| 与现在事实相反 | 过去时（be 用 were） | would / could / might + 动词原形 | If I were you, I would study harder. 如果我是你，我会更努力学习。 |
| 与过去事实相反 | had + 过去分词 | would / could / might + have + 过去分词 | If I had studied hard, I would have passed. 如果我当时努力学习，我就通过了。 |
| 与将来事实相反 | should + 动词原形 / were to + 动词原形 / 过去时 | would / could / might + 动词原形 | If it should rain tomorrow, we would stay home. 万一明天下雨，我们就待在家。 |

### 20.3 混合虚拟
有时从句和主句的时间不一样，各自按自己的时间「倒退一格」：
If I had taken your advice, I would be happy now.
如果我当时听了你的建议，我现在就会很开心。
（从句对过去虚拟：had done；主句对现在虚拟：would be）
### 20.4 wish / would rather / as if 虚拟
I wish I were a bird.（对现在：过去时 were）
我希望我是一只鸟。
I wish I had gone to the party.（对过去：had done）
我真希望我当时去了那个聚会。
I would rather you stayed here.（对现在/将来：过去时）
我宁愿你待在这里。
He talks as if he were the boss.（像…一样：过去时）
他说起话来好像他是老板一样。
### 20.5 建议、命令、要求类动词后的虚拟
suggest（建议）、require（要求）、insist（坚持）、order（命令）、demand（要求）等动词后面的 that 从句，要用「should + 动词原形」，should 常常省略：
I suggest (that) he (should) see a doctor.
我建议他去看医生。
The teacher required (that) we (should) hand in our homework on time.
老师要求我们按时交作业。
### 20.6 It's time that
It's time that we went to bed.
= It's time for us to go to bed.
我们该睡觉了。（从句用过去时）
### 20.7 易错点
**【易错】**① 虚拟语气中 be 动词一律用 were，不管主语是谁：If I were you / If he were here。② 对过去虚拟的公式是 had done + would have done，别漏 have：If I had known, I would come 是错的，要说 would have come。③ suggest 表「建议」时后面才用 should + 动词原形；suggest 表「暗示、表明」时用陈述语气：His face suggested that he was angry.（暗示）。
**【技巧】**④ 非虚拟的 if 条件句（可能发生的事）用「主将从现」，虚拟的 if 条件句（不可能发生的事）才用倒退时态，做题时先判断「真的假的」。
## 第21章 其他高频语法点
### 21.1 比较级与最高级
比较级（更……）用于两者比较，最高级（最……）用于三者以上比较。变化规则：

| 规则 | 怎么变 | 例子 |
| --- | --- | --- |
| 一般单音节词 | 直接加 er / est | tall → taller → tallest |
| 以 e 结尾 | 加 r / st | large → larger → largest |
| 辅音字母 + y 结尾 | 变 y 为 i，加 er / est | happy → happier → happiest |
| 重读闭音节 | 双写末尾辅音，加 er / est | big → bigger → biggest |
| 多音节词 | 前面加 more / most | beautiful → more beautiful → most beautiful |
| 不规则 | 特殊变化 | good / well → better → best; bad → worse → worst; many / much → more → most; little → less → least |

as...as 和……一样：She is as tall as her mother. 她和她妈妈一样高。
not so...as 不如：He is not so tall as you. 他没有你高。
the + 比较级……the + 比较级…… 越……越……：The more you read, the more you learn. 你读得越多，学得越多。
比较级 + and + 比较级 越来越……：It is getting colder and colder. 天越来越冷了。
**【易错】**两者比较用比较级，三者以上用最高级（最高级前要加 the）。修饰比较级用 much / even / a little：much better（好得多），very 不能修饰比较级。
### 21.2 冠词 a / an / the

| 冠词 | 用法 | 例子 |
| --- | --- | --- |
| a / an | 泛指「一个」；a 用在辅音音素前，an 用在元音音素前 | a book 一本书；an apple 一个苹果；an hour 一小时 |
| the | 特指「这个、那个」，双方都知道的 | the sun 太阳；the book on the desk 桌上的那本书 |
| 不用冠词 | 复数泛指、人名地名、三餐、球类、学科、季节月份星期 | play basketball 打篮球；have breakfast 吃早饭；in May 在五月 |

**【技巧】**判断用 a 还是 an 看「发音」不看字母：an hour（h 不发音，元音开头）、a university（发 /ju:/ 辅音开头）、an umbrella（元音开头）。
### 21.3 代词

| 类别 | 例子 | 用法要点 |
| --- | --- | --- |
| 人称代词 | I / me, you, he / him, she / her, it, we / us, they / them | 作主语用主格，作宾语用宾格：I love her. |
| 物主代词 | my / mine, your / yours, his, her / hers | 形容词性（my）后跟名词；名词性（mine）单独用：This book is mine. |
| 反身代词 | myself, yourself, himself, herself, itself, ourselves | 动作回到自己身上：I did it myself. |
| 指示代词 | this, that, these, those | 近处用 this / these，远处用 that / those。 |
| 不定代词 | some, any, each, either, neither, none, both, all, few, a few, little, a little | each 每个（两者以上）；either 两者之一；neither 两者都不；none 三者以上都不 |

some / any：肯定句用 some，否定疑问句用 any；表请求时疑问句用 some。
a few / few + 可数名词：a few 几个（有），few 几乎没有（无）。
a little / little + 不可数名词：a little 一点（有），little 几乎没有（无）。
例：I have a few friends. 我有几个朋友。/ He has little money. 他几乎没钱。
### 21.4 介词

| 类别 | 规则 | 例子 |
| --- | --- | --- |
| 时间 in / on / at | at 用于时刻；on 用于具体某天；in 用于月、年、季节 | at 8 o'clock；on Monday；in 2024 |
| 时间 since / for / during | since 自从（点）；for 持续（段）；during 在……期间 | since 2020；for three days；during the holiday |
| 地点 in / on / at | in 在……里（大地方）；on 在……上；at 在……处（小地方） | in Beijing；on the desk；at the station |
| 方位 under / behind / in front of / next to | 在……下 / 后面 / 前面 / 旁边 | under the bed；behind the door；next to the shop |

常用介词短语：
be good at 擅长    be interested in 对……感兴趣    be afraid of 害怕
be full of 充满    look forward to 期待    depend on 依靠
get on well with 与……相处融洽    take care of 照顾
### 21.5 主谓一致
- 就近原则（谓语跟最近的主语走）：neither...nor...、either...or...、not only...but also...。Neither he nor I am right. 他和我都不对。（谓语看最近的 I）
- 就远原则（谓语跟真正的主语走）：with、together with、as well as、along with 只是「附带」成分。The teacher with his students is going there. 老师和学生们正要去那儿。（谓语看 teacher）
- 集合名词：family、team、class 看成一个整体用单数，看成成员用复数。My family is big. / My family are all tall.
- a number of（许多）后谓语用复数；the number of（……的数量）后谓语用单数。A number of students are here. / The number of students is 50.
### 21.6 倒装句
- 部分倒装（把助动词 / be / 情态动词提到主语前）：never、not only、hardly、only + 状语、so / neither 开头时。Never have I seen such a movie. 我从未看过这样的电影。
- 完全倒装（把整个谓语提到主语前）：here、there、方位副词开头，主语是名词时。Here comes the bus. 公交车来了。
Not only did he pass the exam, but he got the first prize.
他不仅通过了考试，还得了第一名。
So am I. / Neither do I.
我也是。/ 我也不（是）。
Hardly had I got home when it began to rain.
我刚到家就下雨了。
### 21.7 强调句
It is / was + 被强调部分 + that / who + 其余部分
It was Tom that broke the window.
是汤姆打破了窗户。（强调 Tom）
It is in the park that we met.
我们是在公园相遇的。（强调 in the park）
**【技巧】**判断是不是强调句的方法：把 It is / was 和 that / who 去掉，剩下的句子仍然完整，就是强调句。It is...that 强调人时可用 who，强调其他一律用 that。
### 21.8 反意疑问句
反意疑问句 = 陈述句 + 简短问句，「前肯后否、前否后肯」，时态和助动词保持一致：
You are a student, aren't you? 你是学生，对吧？
He doesn't like coffee, does he? 他不喜欢咖啡，对吧？
She went home, didn't she? 她回家了，对吧？
Let's go, shall we? 我们走吧，好吗？
Open the door, will you? 开下门，好吗？
**【易错】**① 前面有 never、hardly、few、little、nothing 等否定词时，后面用肯定形式：He never comes late, does he? ② Let's 用 shall we，祈使句用 will you。③ I am 的反意疑问用 aren't I：I am right, aren't I?

## 附录B 时态标志词速查表
做题时看到这些标志词，优先想到对应的时态。注意：标志词只是「信号灯」，最终还要结合语境判断，个别标志词（如 since、for、recently）可以搭配多个时态。

| 时态 | 标志词 |
| --- | --- |
| 一般现在时 | always, usually, often, sometimes, never, every day, on Mondays, twice a week |
| 一般过去时 | yesterday, last week, two days ago, in 2020, just now, the day before yesterday |
| 一般将来时 | tomorrow, next week, soon, later, in the future, this weekend, in three days |
| 过去将来时 | the next day, the following week（主句为过去时的语境） |
| 现在进行时 | now, right now, at the moment, Look!, Listen!, these days |
| 过去进行时 | at 8 o'clock yesterday, at that time, while, this time yesterday |
| 将来进行时 | this time tomorrow, at 9 tomorrow morning, at this time next week |
| 过去将来进行时 | 过去语境中：the next day at that time（极少用） |
| 现在完成时 | already, yet, just, ever, never, since, for, so far, recently, up to now |
| 过去完成时 | by the time, by then, before, after, already, by the end of last year |
| 将来完成时 | by next year, by the end of this month, by the time + 将来从句 |
| 过去将来完成时 | 过去语境中：by the following year（极少用） |
| 现在完成进行时 | since, for, all day, how long, recently, these days |
| 过去完成进行时 | by then, for + 过去时间, all day yesterday, before |
| 将来完成进行时 | by next year, for + 将来时间 |
| 过去将来完成进行时 | 极少用，仅出现在书面语中 |

**【技巧】**高频速记：yesterday / ago → 一般过去时；tomorrow / next → 一般将来时；now / Look / Listen → 现在进行时；since / for / already / yet / just → 现在完成时；by the time → 完成时（过去或将来）。
## 附录C 高频易错点清单
把全书最常踩的坑集中到一起，考前过一遍，错误率立刻下降。

| 易错点 | 正确用法 | 例子 |
| --- | --- | --- |
| 三单主语动词不加 s | 主语是 he / she / it 时动词加 s/es | He likes music.（不是 He like music.） |
| does 后面动词还加 s | does 后动词用原形 | He doesn't like coffee.（不是 doesn't likes） |
| be 动词与实义动词混用 | 一个谓语只能用一种 | I like music.（不是 I am like music.） |
| did 后面动词用过去式 | did 后动词用原形 | He didn't go.（不是 didn't went） |
| was/were 与 did 混用 | be 的过去式不与 did 连用 | He wasn't at home.（不是 He didn't was at home.） |
| will 后面用过去式 | will 后动词用原形 | I will go tomorrow.（不是 will went） |
| there will have | 用 there will be | There will be a meeting.（不是 There will have a meeting.） |
| 进行时漏掉 be | 必须是 be + doing | I am reading.（不是 I reading） |
| 状态动词用进行时 | 状态动词不用进行时 | I know him.（不是 I am knowing him.） |
| 完成时与过去时间词连用 | 完成时不与 yesterday 等连用 | I finished it yesterday.（不是 have finished it yesterday） |
| since 后跟时间段 | since + 时间点，for + 时间段 | since 2020 / for two years |
| 短暂动词与 for/since 连用 | 换成延续性表达 | He has had the bike for 2 years.（不是 has bought） |
| been to 与 gone to 混用 | 已回用 been to，未回用 gone to | He has gone to Beijing.（人不在现场） |
| 过去完成时没有参照点 | 必须配合过去的参照时间 | When I arrived, the train had left. |
| 被动句漏掉 be | 被动 = be + 过去分词 | The house was built in 2000.（不是 The house built） |
| 不及物动词用被动 | 不及物动词没有被动 | The accident happened.（不是 was happened） |
| mustn't 表推测的否定 | 推测否定用 can’t | He can't be at home.（不是 mustn't） |
| must 的否定用 mustn't | 「不必」用 needn’t / don’t have to | You don't have to finish it today. |
| 情态动词后加 to | 情态动词后动词原形（have to 除外） | He can swim.（不是 can to swim） |
| enjoy 后接 to do | enjoy / finish / avoid 后接 doing | I enjoy reading.（不是 enjoy to read） |
| forget to do 与 doing 混用 | to do 表未做，doing 表已做 | I forgot to lock the door.（门没锁） |
| 宾语从句用疑问语序 | 从句必须用陈述语序 | Do you know where she lives?（不是 where does she live） |
| 定语从句中重复代词 | 去掉重复的 it / them | This is the book (that) I bought.（不是 bought it） |
| because 与 so 连用 | 两者只用其一 | Because he was ill, he didn't come. |
| although 与 but 连用 | 两者只用其一 | Although it rained, we went out. |
| 主将从现的从句用 will | 时间/条件从句用一般现在时 | If it rains tomorrow, we will stay home. |
| so 与 such 混用 | so + 形容词/副词，such + 名词 | so hot / such a hot day |
| 比较级前用 very | 修饰比较级用 much / even | much better（不是 very better） |
| a/an 看字母判断 | 看发音判断 | an hour / a university |
| 反意疑问前后不一致 | 前肯后否、前否后肯 | He never comes late, does he? |

**【提示】**以上 30 条是历年考试和日常写作中出现频率最高的错误。建议每周过一遍，做题时遇到对应情况立刻想起表格里的「正确用法」。
