## 第1章 数学（数学一/二）经典真题例题
本章学习目标：通过 12 道「真题改编」例题，覆盖极限、导数与中值定理、定积分、微分方程、无穷级数（数一）、二重积分六大高频考点。每道题都按"题目 → 思路点拨 → 详细步骤 → 答案"四步展开，请先自己做，再看答案。
**【提示】**数学是最需要"动笔"的科目：看十遍不如做一遍。每道例题请先在草稿纸上完整写出过程，再对照详细步骤找差距。
### 1.1 极限（2 题）
方法提醒：拿到极限题，先判断"型"：0/0 型、∞/∞ 型、1^∞ 型、∞-∞ 型……再选工具：等价无穷小替换、洛必达法则、泰勒展开、两个重要极限、夹逼准则。0/0 型优先考虑提公因式 + 等价无穷小。
#### 例1.1.1（真题改编）：求极限 lim(x→0) (tan x - sin x)/x^3
**【思路点拨】**这是 0/0 型。表面上是"两个函数相减"，不能直接对加减项做等价无穷小替换；正确做法是先把 sin x 提出来，变成"乘除结构"再替换。
lim(x→0) (tan x - sin x)/x^3
= lim(x→0) sin x·(1/cos x - 1)/x^3      （提出公因式 sin x）
= lim(x→0) sin x·(1 - cos x)/(x^3·cos x) （通分整理，化成乘除结构）
等价无穷小：sin x ~ x，1 - cos x ~ x^2/2，且 x→0 时 cos x → 1
原式 = lim(x→0) x·(x^2/2)/(x^3·1)
     = lim(x→0) (x^3/2)/x^3
     = 1/2
**答案：1/2。**
**【易错】**等价无穷小只能替换"乘除因子"，不能直接替换"加减项"。本题如果上来就把 tan x ~ x、sin x ~ x 代入，会得到 0/0 的假象，属于高频错误。
#### 例1.1.2（真题改编，1^∞ 型）：求极限 lim(x→∞) ((x+2)/(x-1))^x
**【思路点拨】**底数趋于 1、指数趋于无穷，是典型的 1^∞ 型。套路：把底数凑成"1 + 小量"，利用重要极限 lim(u→∞)(1 + 1/u)^u = e。
先变形底数：(x+2)/(x-1) = (x-1+3)/(x-1) = 1 + 3/(x-1)
令 u = (x-1)/3，则 x = 3u + 1，x→∞ 时 u→∞
原式 = lim(u→∞) (1 + 1/u)^(3u+1)
     = lim(u→∞) [(1 + 1/u)^u]^3 · (1 + 1/u)
     = e^3 · 1
     = e^3
**答案：e^3。**
**【技巧】**1^∞ 型口诀："底数凑 1，指数乘回去"。更快的公式：若底数形如 1 + k/x（k 为常数），则极限直接为 e^k，本题 k=3。
### 1.2 导数与中值定理（2 题）
方法提醒：中值定理题先看结论长什么样：结论是 f(ξ)=0 类 → 优先罗尔定理；结论是 (f(b)-f(a))/(b-a) 类 → 优先拉格朗日中值定理。使用前必须写清"连续、可导"两个条件。
#### 例1.2.1（真题改编）：设 f(x) 在 [0,1] 上连续，在 (0,1) 内可导，且 f(0)=0，f(1)=1。证明：存在 ξ∈(0,1)，使得 f'(ξ)=1。
**【思路点拨】**目标 f'(ξ)=1 正好是拉格朗日中值定理的结论形式：(f(1)-f(0))/(1-0)=1。条件（连续、可导）都满足，直接套定理。
f(x) 在 [0,1] 上连续，在 (0,1) 内可导，满足拉格朗日中值定理的全部条件。
由拉格朗日中值定理：存在 ξ∈(0,1)，使得
f'(ξ) = (f(1) - f(0))/(1 - 0) = (1 - 0)/1 = 1
命题得证。
**答案：存在 ξ∈(0,1)，使 f'(ξ)=1，证毕。**
**【易错】**中值定理题是按步骤给分的："连续、可导"条件一句、定理名称一句、代入计算一句，缺一步都可能扣分。
#### 例1.2.2（真题改编）：求函数 f(x)=x^3-3x 在闭区间 [-2,2] 上的最大值与最小值。
**【思路点拨】**闭区间上连续函数的最值，只可能在"端点、驻点、不可导点"处取得。本题 f 处处可导，只需比较端点值与驻点值。
求导：f'(x) = 3x^2 - 3 = 3(x^2 - 1)
令 f'(x) = 0，得驻点 x = ±1（均在 [-2,2] 内）
计算函数值：
f(-2) = (-2)^3 - 3·(-2) = -8 + 6 = -2
f(-1) = (-1)^3 - 3·(-1) = -1 + 3 = 2
f(1)  = 1^3 - 3·1 = 1 - 3 = -2
f(2)  = 2^3 - 3·2 = 8 - 6 = 2
比较四个值：最大值为 2，最小值为 -2
**答案：最大值 2（x=-1 或 x=2 处取得）；最小值 -2（x=-2 或 x=1 处取得）。**
### 1.3 定积分（2 题）
方法提醒：定积分计算三大工具——牛顿-莱布尼茨公式（找原函数）、换元法、分部积分法。看到 x·e^x、x·sin x 这类"乘积"优先分部积分；看到 √(a^2-x^2) 这类结构优先想几何意义或三角换元。
#### 例1.3.1（真题改编）：计算定积分 ∫(0,1) x·e^x dx。
**【思路点拨】**被积函数是幂函数 × 指数函数，用分部积分：∫u dv = uv - ∫v du。口诀"反对幂指三"：按反三角、对数、幂、指数、三角的顺序，越靠前越优先设为 u，所以取 u=x。
∫(0,1) x·e^x dx
令 u = x，dv = e^x dx，则 du = dx，v = e^x
= [x·e^x](0,1) - ∫(0,1) e^x dx
= (1·e^1 - 0·e^0) - [e^x](0,1)
= e - (e - 1)
= 1
**答案：1。**
#### 例1.3.2（真题改编）：利用几何意义计算定积分 ∫(0,2) √(4-x^2) dx。
**【思路点拨】**y=√(4-x^2) 的图像是圆心在原点、半径 r=2 的上半圆。定积分的几何意义是"曲线与 x 轴围成的面积"，本题正好对应第一象限的四分之一圆。
y = √(4-x^2)  ⇔  x^2 + y^2 = 4（且 y ≥ 0），即半径 r = 2 的上半圆
x ∈ [0,2] 对应第一象限部分，正好是四分之一圆
由定积分的几何意义：
∫(0,2) √(4-x^2) dx = 四分之一圆面积 = (1/4)·π·r^2 = (1/4)·π·4 = π
**答案：π。**
**【技巧】**看到 √(a^2-x^2) 不要急着换元，先画图想几何意义，往往一步出结果；这也是真题喜欢考的"偷懒技巧"。
### 1.4 微分方程（2 题）
方法提醒：拿到微分方程先"认类型"：可分离变量型、一阶线性型 y'+P(x)y=Q(x)、二阶常系数齐次型。认对类型再动手，比硬算重要得多。
#### 例1.4.1（真题改编）：求微分方程 y' + 2y = e^(-x) 的通解。
**【思路点拨】**标准的一阶线性非齐次方程。用积分因子法：积分因子 μ=e^(∫P dx)，两边同乘后左边恰好是 (y·μ)'，再两边积分即可。
P(x) = 2，Q(x) = e^(-x)
积分因子 μ = e^(∫2 dx) = e^(2x)
方程两边同乘 e^(2x)：
e^(2x)·y' + 2e^(2x)·y = e^(2x)·e^(-x) = e^x
左边 = (y·e^(2x))'，所以 (y·e^(2x))' = e^x
两边积分：y·e^(2x) = e^x + C
通解：y = e^(-x) + C·e^(-2x)（C 为任意常数）
**答案：y = e^(-x) + C·e^(-2x)。**
#### 例1.4.2（真题改编）：求微分方程 y'' - 3y' + 2y = 0 满足 y(0)=0、y'(0)=1 的特解。
**【思路点拨】**二阶常系数齐次方程，三步走：①写特征方程 ②解出特征根 ③按根的类型写通解，再用初值条件定出常数。
特征方程：r^2 - 3r + 2 = 0
因式分解：(r - 1)(r - 2) = 0，得 r1 = 1，r2 = 2（两个不等实根）
通解：y = C1·e^x + C2·e^(2x)
求导：y' = C1·e^x + 2·C2·e^(2x)
代入 y(0)=0：C1 + C2 = 0
代入 y'(0)=1：C1 + 2C2 = 1
联立解得：C2 = 1，C1 = -1
特解：y = -e^x + e^(2x)
**答案：y = -e^x + e^(2x)。**
**【易错】**特征根三种情况要分清：两个不等实根 → y = C1·e^(r1 x) + C2·e^(r2 x)；重根 → y = (C1 + C2·x)·e^(rx)；共轭复根 → y = e^(αx)(C1·cosβx + C2·sinβx)。
### 1.5 无穷级数·数一（2 题）
方法提醒（数一专属考点）：判断级数敛散性，先看通项是否趋于 0（必要条件，不满足直接发散）；正项级数用比较审敛法、比值审敛法；交错级数用莱布尼茨判别法；最后还要分清"收敛"与"绝对收敛、条件收敛"。
#### 例1.5.1（真题改编）：判别级数 Σ(n=1→∞) (-1)^(n-1)/n 的敛散性，并说明是绝对收敛还是条件收敛。
**【思路点拨】**这是"交错调和级数"：先看绝对值级数 Σ1/n（调和级数，发散），再看原级数是否满足莱布尼茨条件（通项单调递减趋于 0，满足），所以是条件收敛。
第一步：考察绝对值级数
Σ|(-1)^(n-1)/n| = Σ(1/n)，这是调和级数，发散
第二步：用莱布尼茨判别法考察原级数
a_n = 1/n 单调递减，且 lim(n→∞) a_n = 0
交错级数 Σ(-1)^(n-1)·a_n 收敛
第三步：结论
原级数收敛，但绝对值级数发散 → 原级数条件收敛
**答案：原级数条件收敛。**
**【易错】**"收敛"和"绝对收敛"是两回事：只有"绝对值级数也收敛"才能叫绝对收敛。判断顺序一定是：先判绝对值级数，再判原级数。
#### 例1.5.2（真题改编）：求幂级数 Σ(n=0→∞) x^n/n! 的和函数，并由此计算 Σ(n=0→∞) 1/n! 的值。
**【思路点拨】**看到分母有 n!，立刻想到 e^x 的麦克劳林展开：e^x = Σ(n=0→∞) x^n/n!。这是"背过的公式直接套"的送分题。
e^x 的麦克劳林展开：
e^x = 1 + x + x^2/2! + x^3/3! + ... = Σ(n=0→∞) x^n/n!（收敛域为全体实数 R）
所以幂级数 Σ(n=0→∞) x^n/n! 的和函数为 S(x) = e^x
令 x = 1：Σ(n=0→∞) 1/n! = e^1 = e
**答案：和函数 S(x)=e^x；Σ(n=0→∞) 1/n! = e。**
**【重点】**五个常用展开必须背熟：e^x、sin x、cos x、1/(1-x)、ln(1+x)。考场上很多级数题都是"换元 + 套展开"。
### 1.6 二重积分（2 题）
方法提醒：二重积分先画积分区域 D：①区域或被积函数含 x^2+y^2 → 用极坐标；②否则用直角坐标，选好积分次序（先积的变量写在里层）。
#### 例1.6.1（真题改编）：计算二重积分 ∬_D (x+y) dxdy，其中 D 是由直线 y=x、y=0、x=1 围成的三角形闭区域。
**【思路点拨】**先画图：三角形顶点为 (0,0)、(1,0)、(1,1)，区域可写成 0≤x≤1，0≤y≤x。先对 y 积分（内层），再对 x 积分（外层）。
D = {(x,y) | 0 ≤ x ≤ 1，0 ≤ y ≤ x}
∬_D (x+y) dxdy = ∫(0,1) dx ∫(0,x) (x+y) dy
内层积分（对 y）：
∫(0,x) (x+y) dy = [x·y + y^2/2](0,x) = x^2 + x^2/2 = (3/2)x^2
外层积分（对 x）：
∫(0,1) (3/2)x^2 dx = (3/2)·(1/3) = 1/2
**答案：1/2。**
#### 例1.6.2（真题改编）：计算二重积分 ∬_D (x^2+y^2) dxdy，其中 D 为圆域 x^2+y^2 ≤ 1。
**【思路点拨】**被积函数和积分区域都含 x^2+y^2，果断换极坐标：x=r·cosθ，y=r·sinθ，面积微元 dxdy = r·dr·dθ，圆域化为 0≤r≤1、0≤θ≤2π。
极坐标变换：x = r·cosθ，y = r·sinθ，x^2+y^2 = r^2，dxdy = r·dr·dθ
区域 D：0 ≤ r ≤ 1，0 ≤ θ ≤ 2π
原式 = ∫(0,2π) dθ ∫(0,1) r^2·r dr = ∫(0,2π) dθ ∫(0,1) r^3 dr
内层积分（对 r）：∫(0,1) r^3 dr = r^4/4 |(0,1) = 1/4
外层积分（对 θ）：∫(0,2π) (1/4) dθ = (1/4)·2π = π/2
**答案：π/2。**
**【易错】**极坐标换元千万别漏掉"多出来的那个 r"（雅可比行列式），dxdy = r dr dθ，这是二重积分极坐标最高频的丢分点。
**【提示】**本章小结：12 道题覆盖了数学一/二最核心的六大考点。学完本章后，请把 6 个"方法提醒"抄到笔记本第一页，做题前先对照提醒选方法。
## 第2章 英语真题用法与示例
本章学习目标：理解 2010—2024 年英语真题的价值，学会"定位 + 同义替换"的阅读解题法，掌握图画作文三段式写法。
### 2.1 2010—2024 年英语真题的价值
为什么真题比任何模拟题都重要？因为英语真题的"出题基因"是稳定的：
- 词汇复现率高：真题高频词在历年试卷中反复出现，做透真题等于背了最精准的单词表。
- 题源稳定：阅读理解多选自《经济学人》《卫报》《科学美国人》等英美主流报刊，题材（科技、社会、教育、经济）高度集中。
- 出题套路固定：细节题考"定位 + 同义替换"，主旨题考"首尾段概括"，态度题考"形容词色彩"——套路是可以练出来的。
- 作文题型稳定：英语一考图画作文（大作文），英语二考图表作文；小作文都是书信/通知等应用文，模板化程度高。
**【提示】**真题使用三遍法：第一遍按考试限时做（找感觉）；第二遍精读，查生词、逐句翻译（打基础）；第三遍只研究选项，分析每个干扰项错在哪（提正确率）。
### 2.2 真题风格阅读段落示例（风格仿真题，非真题原文）
下面这段英文是仿照考研英语一阅读理解风格自拟的段落（说明：本段为仿真材料，用于训练解题方法，并非任何一年真题原文）。请先限时 8 分钟完成后面两道题，再看解析。
Technological advances have long been a source of both excitement and anxiety. On the one hand, innovations in artificial intelligence and automation promise to raise productivity, cut costs and improve the quality of services. On the other hand, many workers fear that machines will replace them, leaving millions unemployed. History, however, suggests that such fears, though understandable, are often exaggerated. When the automobile replaced the horse and carriage, new jobs emerged in road construction, fuel supply and vehicle maintenance. Similarly, the rise of the personal computer created an entire industry of software developers, network engineers and digital marketers that had not existed before. What matters, economists argue, is not whether technology destroys jobs, but whether society can help workers adapt. Education and training, social safety nets and flexible labour markets all play a part in ensuring that the benefits of technological change are widely shared rather than concentrated in the hands of a few.
**题目 1：The author mentions the automobile and the personal computer in order to ______.**
- A. show that old industries always disappear quickly
- B. illustrate that technology can create new jobs and industries
- C. prove that machines are more productive than human beings
- D. suggest that workers should resist technological change
**【定位句】**定位句："When the automobile replaced the horse and carriage, new jobs emerged... Similarly, the rise of the personal computer created an entire industry..."。两个例子都说明"新技术带来新职业、新行业"，是论证"技术创造就业"这一观点。
原文：new jobs emerged in road construction, fuel supply and vehicle maintenance
      created an entire industry of software developers...
同义替换：new jobs emerged / created an entire industry → create new jobs and industries
干扰项分析：
A. "旧行业总是很快消失"——原文只说出现新工作，并未说旧行业消失，过度推断
C. "机器比人更有生产力"——原文未比较生产力高低，无中生有
D. "工人应抵制技术变革"——与原文"fears...are often exaggerated"态度相反
**答案：B。**
**题目 2：According to the passage, what is essential for workers to benefit from technological change?**
- A. Resisting the introduction of new technology
- B. Reducing the number of workers in every industry
- C. Helping workers adapt through education and training
- D. Concentrating the benefits in the hands of a few
**【定位句】**定位句："What matters... is not whether technology destroys jobs, but whether society can help workers adapt. Education and training, social safety nets and flexible labour markets all play a part..."。
原文：whether society can help workers adapt；Education and training... all play a part
同义替换：help workers adapt + Education and training → helping workers adapt through education and training
干扰项分析：
A. "抵制新技术"——与原文"fears are often exaggerated"的态度相悖
B. "减少每个行业的工人数量"——原文没有这个建议，无中生有
D. "把好处集中在少数人手里"——原文明确说 benefits should be "widely shared rather
    than concentrated in the hands of a few"，与原文相反
**答案：C。**
**【技巧】**阅读解题核心四步：①先读题干划关键词 ②回原文定位 ③比对原文与选项找同义替换 ④排除干扰项（无中生有、偷换概念、以偏概全、与原文相反）。
### 2.3 大作文真题风格示例（图画作文）
题目描述（仿真题）：Directions: Write an essay of 160-200 words based on the following drawing. In your essay, you should 1) describe the drawing briefly, 2) explain its intended meaning, and 3) give your comments. 图画内容：一位考研学生坐在书桌前，双眼紧盯手机屏幕，屏幕上写着"刷短视频 3 小时"；桌上一摞复习资料落满灰尘；墙上的日历显示"距考研还有 60 天"。
**【重点】**图画作文铁律：第一段只描述图画（不发表观点），第二段点寓意（联系现实），第三段给建议（2-3 条具体措施）。写成"夹叙夹议"最容易跑题。
**第一段范文要点（描述图画）：**
As is vividly depicted in the drawing, a graduate-school candidate is sitting at a
desk, staring intently at his smartphone, while the textbooks on the desk are
covered with dust. What makes the scene even more striking is the calendar on the
wall, which reminds us that the entrance examination is only sixty days away.
（要点：客观描述人物动作 + 环境细节 + 配文，用 while 连接对比，1-2 句收尾）
**第二段范文要点（阐释寓意）：**
The drawing is intended to convey the message that time management and
self-discipline are of vital importance for those who pursue further education.
Nowadays, many young people are addicted to short videos and social media, which
consume their precious time and weaken their willpower. As a result, their study
plans are constantly delayed and anxiety grows.
（要点：第一句点明寓意，第二句联系现实举例，第三句说明危害，层层递进）
**第三段范文要点（评论建议）：**
In my view, we should take effective measures to resist the temptation of digital
entertainment. To begin with, making a detailed study plan and strictly following
it can help us stay on track. Moreover, keeping the smartphone away during study
hours and using a timer to focus are simple but practical methods. Only by
cherishing every minute can we realize our dream of entering graduate school.
（要点：2-3 条可行建议 + Only by... can we... 倒装句结尾升华）
**【技巧】**万能句式积累：开头 As is vividly depicted in the drawing...；寓意 The picture is intended to convey that...；结尾 Only by... can we...。考前至少各背 3 个替换句，考场上直接套。
## 第3章 思政真题题型示例
本章学习目标：通过单选、多选、分析题三种题型的真题风格示例，掌握思政（政治）科目的命题规律与答题模板。
**【提示】**思政科目特点：选择题重"概念辨析"，分析题重"原理 + 材料"。单选考记忆，多选考理解，分析题考"原理-分析-总结"的模板化表达。
### 3.1 单项选择题（3 题）
方法提醒：单选题要"先排除再选定"。先排除明显错误的说法（如偷换概念、绝对化表述），再在剩余选项中比较，选最准确的一个。
**第 1 题：马克思主义最鲜明的品格是（　）。**
- A. 科学性
- B. 革命性
- C. 实践性
- D. 人民性
**答案：D。**
解析：习近平指出，马克思主义之所以具有跨越国度、跨越时代的影响力，就是因为它植根人民之中，指明了依靠人民推动历史前进的人间正道。人民至上是马克思主义的政治立场，人民性是马克思主义最鲜明的品格。其余三项虽然都是马克思主义的重要特征，但"最鲜明"的定位是人民性。
**第 2 题：意识的本质是（　）。**
- A. 人脑的机能，是对客观世界的主观映象
- B. 人脑分泌出来的特殊物质
- C. 独立于物质世界之外的神秘精神力量
- D. 与生俱来、纯粹主观自生的东西
**答案：A。**
解析：从生理基础上看，意识是人脑的机能和属性；从内容上看，意识是客观世界在人脑中的主观映象。B 把意识说成"分泌物"，是庸俗唯物主义观点；C 是客观唯心主义观点；D 是主观唯心主义观点。
**第 3 题：实践之所以能够成为检验真理的唯一标准，主要是因为（　）。**
- A. 实践具有直接现实性，能把主观认识与客观实际联系起来
- B. 实践是每个人都可以随便进行的活动
- C. 实践可以脱离理论的指导独立进行
- D. 实践的结果总是与主观愿望完全一致
**答案：A。**
解析：真理的本性是主观与客观相符合。要检验认识是否与客观实际相符合，必须把主观认识与客观结果加以对照，而只有实践具有直接现实性——它能将主观认识转化为客观现实，从而完成检验。B、C、D 表述均不准确。
### 3.2 多项选择题（3 题）
方法提醒：多选题"宁可少选，不可错选"？不对！考研政治多选题少选、多选、错选都不得分，所以必须把每个选项都判断对错。逐项判断，对的就选。
**第 1 题：实践对认识的决定作用表现在（　）。**
- A. 实践是认识的来源
- B. 实践是认识发展的动力
- C. 实践是检验认识真理性的唯一标准
- D. 实践是认识的目的
**答案：ABCD。**
解析：四个选项分别对应"来源、动力、标准、目的"四个维度，构成实践决定认识的完整表述。A 对：认识产生于实践的需要；B 对：实践不断提出新问题推动认识深化；C 对：实践是检验真理的唯一标准；D 对：认识最终要回到实践中去指导实践。
**第 2 题：关于量变与质变的辩证关系，下列说法正确的有（　）。**
- A. 量变是质变的必要准备
- B. 质变是量变的必然结果
- C. 量变和质变相互渗透、相互转化
- D. 量变与质变彼此独立、互不相关
**答案：ABC。**
解析：A 对：没有量变的积累，不可能发生质变；B 对：量变达到一定程度必然引起质变；C 对：量变中有部分质变，质变中有量的扩张，二者相互渗透，且在一定条件下相互转化；D 错：该说法割裂了量变与质变的联系，是形而上学的观点。
**第 3 题：关于社会存在与社会意识的关系，下列说法正确的有（　）。**
- A. 社会存在决定社会意识
- B. 社会意识具有相对独立性
- C. 社会意识对社会存在具有能动的反作用
- D. 社会意识决定社会存在
**答案：ABC。**
解析：A 对：社会存在决定社会意识，是历史唯物主义的基本观点；B 对：社会意识有时会超前或落后于社会存在的发展，具有相对独立性；C 对：正确的社会意识促进社会发展，错误的社会意识阻碍社会发展；D 错：颠倒了社会存在与社会意识的关系，是历史唯心主义的观点。
### 3.3 分析题（1 题）
**【思路点拨】**方法提醒：分析题不要求你写得多"创新"，而是要求"踩点准确、结构完整"。最稳的作答模板是三步走：原理 → 分析 → 总结。
**材料一：人工智能正在深刻改变人类的生产生活方式。它大幅提升了生产效率，催生了新的产业和就业形态，成为引领新一轮科技革命和产业变革的战略性技术。**
**材料二：人工智能的发展也带来新的问题与挑战，如部分岗位被替代导致的结构性失业、算法歧视与数据安全风险、责任归属与伦理争议等。有人因此对人工智能的发展前景感到担忧。**
**问题：（1）运用唯物辩证法矛盾学说的有关原理，说明为什么人工智能的发展"既有机遇又有挑战"；（2）结合材料，谈谈我们应该如何正确对待人工智能发展中的机遇与挑战。**
**【重点】**作答示范（按"原理-分析-总结"模板）：
【原理】矛盾具有普遍性：矛盾存在于一切事物发展的过程中，事事有矛盾、时时有
矛盾。任何事物都包含着既对立又统一的两个方面；同时，矛盾的主要方面与次
要方面相互区别、相互转化，要求我们坚持两点论与重点论的统一。
【分析】人工智能作为新生事物，其发展过程本身包含着矛盾：一方面，它提高生
产效率、推动产业升级、催生新业态，这是矛盾的主要方面，代表了社会进步的
方向（对应材料一）；另一方面，它带来就业结构调整、数据安全、伦理道德等
新问题，这是矛盾的次要方面（对应材料二）。机遇与挑战并存，正是矛盾双方
对立统一的表现。二者在一定条件下还会相互转化：应对得当，挑战可以转化为
机遇；放任不管，机遇也可能演变为风险。材料二中部分人的担忧，只看到了矛
盾的次要方面而低估了主要方面，是用片面的观点看问题。
【总结】因此，我们要坚持两点论与重点论的统一：既看到人工智能带来的巨大机
遇，坚定发展信心；又正视其带来的挑战，未雨绸缪。具体而言，应完善相关法
律法规，健全就业培训与保障体系，推动人机协作，让科技发展更好地造福人民。
**【技巧】**模板口诀："原理亮名 + 内容一句，分析扣材料 + 正反两面，总结扣题 + 具体措施"。每步写 2-3 句，不要只背原理不结合材料，也不要只抄材料不写原理。
## 第4章 电子技术基础真题题型示例
本章学习目标：通过模电 2 题、数电 2 题，掌握"共射放大电路静态与动态分析""运放电路计算""卡诺图化简""同步计数器设计"四类高频考点。
### 4.1 模拟电子技术（2 题）
#### 例4.1.1（真题改编）：共射放大电路如图，Vcc=12V，Rb=300kΩ，Rc=4kΩ，RL=4kΩ，晶体管 β=50，U_BE(on)=0.7V，r_bb'=300Ω。求：(1) 静态工作点 Q（I_BQ、I_CQ、U_CEQ）；(2) 电压放大倍数 Av；(3) 输入电阻 Ri 与输出电阻 Ro。
**【思路点拨】**分两步走：先画"直流通路"（电容开路、信号源短路）求 Q 点；再画"交流微变等效电路"（电容短路、Vcc 对地短路）求 r_be，最后套公式算 Av、Ri、Ro。
(1) 静态工作点 Q（直流通路，电容开路）
I_BQ = (Vcc - U_BE)/Rb = (12 - 0.7)/300k ≈ 0.0377 mA = 37.7 μA
I_CQ = β·I_BQ = 50 × 0.0377 ≈ 1.88 mA
U_CEQ = Vcc - I_CQ·Rc = 12 - 1.88 × 4 ≈ 4.5 V
→ Q 点：I_BQ ≈ 37.7 μA，I_CQ ≈ 1.88 mA，U_CEQ ≈ 4.5 V
(2) 交流参数 r_be（I_EQ ≈ I_CQ = 1.88 mA）
r_be = r_bb' + (1+β)·26/I_EQ ≈ 300 + 51 × 26/1.88 ≈ 300 + 705 ≈ 1.0 kΩ
(3) 电压放大倍数与输入输出电阻
Av = -β·(Rc//RL)/r_be = -50 × (4k//4k)/1.0k = -50 × 2 = -100
Ri = Rb // r_be ≈ 1.0 kΩ（Rb=300kΩ 远大于 r_be，并联后约等于 r_be）
Ro = Rc = 4 kΩ
**答案：Q 点：I_BQ≈37.7μA、I_CQ≈1.88mA、U_CEQ≈4.5V；Av≈-100；Ri≈1.0kΩ；Ro=4kΩ。**
**【易错】**Av 为负号表示输出与输入反相，这是共射放大电路的标志性结论。计算 r_be 时，26 的单位是 mV，电流必须用 mA，单位配错答案必错。
#### 例4.1.2（真题改编）：反相求和运算电路如图，R1=10kΩ，R2=20kΩ，Rf=100kΩ，输入电压 u1=0.2V，u2=-0.1V，求输出电压 u_o。
**【思路点拨】**理想运放两大法宝："虚短"（u- ≈ u+）与"虚断"（流入运放的电流为 0）。反相输入端因 u+ 接地而"虚地"（u- ≈ 0），所有输入电流都流过 Rf。
由"虚断"：流入运放输入端的电流为 0，故 i1 + i2 = if
i1 = u1/R1 = 0.2/10k = 0.02 mA
i2 = u2/R2 = (-0.1)/20k = -0.005 mA
if = i1 + i2 = 0.02 - 0.005 = 0.015 mA
由"虚短"：u- ≈ u+ = 0（反相输入端虚地）
u_o = -if·Rf = -0.015 mA × 100 kΩ = -1.5 V
**答案：u_o = -1.5V。**
**【技巧】**反相求和电路有现成公式：u_o = -Rf·(u1/R1 + u2/R2)，直接代入即可。注意公式最前面的负号不能丢，这是最常扣分的地方。
### 4.2 数字电子技术（2 题）
#### 例4.2.1（真题改编）：用卡诺图化简逻辑函数 F(A,B,C,D)=Σm(0,2,4,5,6,7,8,10,13)，写出最简与或式。
**【思路点拨】**4 变量卡诺图共 16 格，行按 AB、列按 CD 排列（顺序 00、01、11、10）。画圈原则：圈尽量大（1、2、4、8 个）、圈的个数尽量少、每个新圈至少含一个未被圈过的 1。
画卡诺图并标出所有"1"：
        CD  00  01  11  10
AB
00          1   0   0   1    （m0  m1  m3  m2）
01          1   1   1   1    （m4  m5  m7  m6）
11          0   1   0   0    （m12 m13 m15 m14）
10          1   0   0   1    （m8  m9  m11 m10）
画圈（共 3 个圈）：
① 行 AB=01 整行 4 格（m4 m5 m7 m6）→ 对应 A'B
② 四个角 2×2 块（m0 m2 m8 m10，循环相邻）→ 对应 B'D'
③ 第 01 列上 m5 与 m13 的竖对 → 对应 BC'D
最简与或式：F = A'B + B'D' + BC'D
**答案：F = A'B + B'D' + BC'D。**
**【易错】**卡诺图的行列顺序必须是格雷码 00、01、11、10，相邻两格只能有一个变量变化；圈可以跨越上下边界和左右边界（循环相邻），这是初学者最容易漏掉的圈法。
#### 例4.2.2（真题改编）：用 74LS160 设计一个模 7 计数器（清零法），写出设计思路并说明有效状态。
**【思路点拨】**74LS160 是同步十进制计数器，清零端 CLR' 为同步低电平有效（只在 CP 上升沿起作用）。用同步清零芯片构成模 N 计数器时，译码的是「N-1」这个状态——这是与 74LS90 等异步清零芯片（译码 N）的关键区别。
(1) 确定有效状态：0000 → 0001 → ... → 0110，共 7 个状态（0~6），即模 7
(2) 译码最后一个有效状态 0110（十进制 6）：
    用与非门对 Q2、Q1 译码，清零信号 CLR' = (Q2·Q1)'
    当计数到 0110 时 Q2=1、Q1=1，与非门输出低电平 0 送至 CLR'
(3) 连线要点：
    · CLR' 接与非门输出
    · LD' 接高电平（不用置数功能）
    · EP、ET 接高电平（允许计数）
    · D3D2D1D0 悬空或接地均可（未使用置数功能）
(4) 工作过程：
    计数到 0110 时清零信号有效，但清零是同步的，要等下一个
    CP 上升沿到来才真正清零回 0000，随后继续循环计数，
    从而构成模 7 计数器
**答案：有效状态为 0000~0110 共 7 个；清零译码状态为 0110（即 N-1=6）；用与非门实现 CLR'=(Q2·Q1)'，构成模 7 计数器。**
**【重点】**记忆口诀：同步清零译 N-1，异步清零译 N。74LS160/161（同步）译码 N-1；74LS90/192（异步）译码 N。记反了会多计一个状态，是高频易错点。
## 第5章 真题刷题计划

### 5.1 冲刺阶段刷题计划表
下面是冲刺阶段（9 月—考前）的刷题计划表。请结合自身基础，把"任务"细化到每天，并把完成情况记录在错题本首页。

| 月份 | 任务 | 目标 |
| --- | --- | --- |
| 9 月 | 数学：近 15 年真题按题型分块刷；英语：近 10 年阅读精做（三遍法） | 熟悉考法，建立错题本 |
| 10 月 | 数学：成套限时刷（每周 2 套）；英语：完形 + 新题型 + 翻译专项 | 提升速度，稳定正确率 |
| 11 月 | 政治：近 5 年选择题刷 2 遍 + 分析题背模板；专业课：目标院校真题做 2 遍 | 查漏补缺，强化薄弱环节 |

**【技巧】**真题优先级永远高于模拟题：模拟题做得再多，也不如把真题吃透。建议把最近 2-3 年的真题留到 12 月做"全真模拟"，不要提前做完。
### 5.2 错题本的使用方法
#### （1）如何记：一题一页，五个要素
- 题目来源：年份 + 科目 + 题号（如"2021 数学一 第 18 题"），方便回查原题。
- 错误原因：计算失误 / 概念不清 / 方法不会 / 审题错误，四选一或写清组合。
- 正确思路：用自己的话写 2-3 步核心思路，不要抄答案原文。
- 方法标签：这道题用了什么方法（如"分部积分""同步清零译 N-1"），为同类题归类做准备。
- 同类题链接：写下"这道题让我想起____题"，主动建立知识网络。
**【重点】**错题本不是抄题本！只抄题目来源与关键条件，把省下来的时间用来"重做"。重做对了，才说明这道题真正过关。
#### （2）何时复习：按遗忘曲线安排五个节点

| 复习节点 | 复习内容 | 目的 |
| --- | --- | --- |
| 当天晚上 | 不看答案，完整重做一遍 | 趁热打铁，巩固记忆 |
| 3 天后 | 只看思路点拨，再做一遍 | 检验是否真正掌握 |
| 1 周后 | 把同类题换数字、换条件再做 | 举一反三，迁移方法 |
| 考前 1 个月 | 把错题本从头到尾快速过一遍 | 消除盲区，查漏补缺 |
| 考前 3 天 | 只看高频错题与易错点 | 稳定心态，轻装上阵 |

**【提示】**每天固定花 15 分钟回顾错题（比如睡前），比周末集中看 2 小时效果好得多。碎片时间利用起来，积少成多。

## 附录B 答题卡与考试时间提醒
考研初试一般为两天（以准考证为准），各科考试时间与注意事项如下表。

| 科目 | 考试时间 | 满分 | 题型与注意事项 |
| --- | --- | --- | --- |
| 政治 | 第一天 8:30-11:30 | 100 分 | 单选 16 题（1 分/题）、多选 17 题（2 分/题）、分析题 5 题（10 分/题）。多选少选多选均不得分，务必逐项判断。 |
| 英语 | 第一天 14:00-17:00 | 100 分 | 完形 10 分、阅读 40 分、新题型 10 分、翻译 10 分（英一）/15 分（英二）、写作 30 分（英一）/25 分（英二）。写作先列提纲再动笔。 |
| 数学 | 第二天 8:30-11:30 | 150 分 | 选择 10 题（5 分/题）、填空 6 题（5 分/题）、解答 6 题（共 70 分）。解答题按步骤给分，过程写清楚。 |
| 专业课 | 第二天 14:00-17:00 | 150 分 | 各校自命题，题型以目标院校为准。提前确认是否允许使用计算器。 |

**考场注意事项（务必逐条核对）：**
- 提前 30 分钟到达考点，携带准考证和有效身份证件，两证缺一不可。
- 选择题用 2B 铅笔填涂答题卡，主观题用黑色签字笔书写；禁止使用涂改液、修正带。
- 按要求粘贴条形码，答题卡上不得做任何与答题无关的标记。
- 手机等电子设备一律不得带入考场（关机也不行），按考点要求统一存放。
- 草稿纸由考场统一发放，不得带出考场；每科结束后按监考老师要求交回。
- 考前一天务必踩点、查好路线、定好闹钟；考试期间饮食清淡，注意保暖。
