## 第 1 章 函数、极限、连续
### 1.1 什么是函数
大白话：函数就是"一个萝卜一个坑"的对应关系——给你一个 x，能算出唯一的一个 y。
y = f(x)：x 叫自变量，y 叫因变量，f 表示"对应法则"
函数有三要素：定义域（x 能取哪些值）、值域（y 能取哪些值）、对应法则（怎么算）。
**【重点】**考研常考定义域：分母不为 0、根号下非负、对数真数大于 0、反正弦值域 [-1,1]，这些限制要一眼看出来。
### 1.2 基本初等函数（六大类）

| 类别 | 例子 | 说明 |
| --- | --- | --- |
| 常数函数 | y = C | 图像是一条水平直线 |
| 幂函数 | y = x^a | 如 x、x²、x³、√x、1/x |
| 指数函数 | y = a^x（a>0 且 a≠1） | 如 e^x，增长非常快 |
| 对数函数 | y = log_a(x)（a>0 且 a≠1） | 指数函数的反函数，常用 lnx |
| 三角函数 | y = sinx、cosx、tanx 等 | 周期函数，图像是波浪形 |
| 反三角函数 | y = arcsinx、arccosx、arctanx 等 | 值域有限，如 arcsinx ∈ [-π/2, π/2] |

**【重点】**六大类函数的图像和性质必须烂熟：奇偶性、周期性、单调性、值域，选择题最爱考。
### 1.3 极限的定义（大白话版）
大白话：当 x 越来越靠近某个数 a（或者越来越大）时，f(x) 越来越靠近一个固定的数 A，就说 f(x) 的极限是 A。
严格定义（ε-δ 语言，一句话理解）：不管你要求的接近程度 ε 定得多小，我总能找到一个距离 δ，只要 x 离 a 足够近（小于 δ），f(x) 离 A 就一定小于 ε。换句话说：想多近，就能多近。
lim(x→a) f(x) = A 的含义：
∀ε>0，∃δ>0，当 0<|x-a|<δ 时，恒有 |f(x)-A|<ε
**【提示】**ε-δ 定义一般只考选择题的判断，理解"任意小、总能找到"即可，不需要会写完整证明。
### 1.4 左右极限
x 从 a 的左边靠近 a，记作 x→a⁻（左极限）；从右边靠近，记作 x→a⁺（右极限）。
lim(x→a) f(x) 存在 ⇔ 左极限 = 右极限
**【易错】**分段函数在分段点、绝对值函数、取整函数处，一定要分别算左右极限再下结论。
### 1.5 无穷小与等价无穷小
极限为 0 的量叫无穷小。无穷小之间可以比级别（阶），同阶且比值为 1 的叫等价无穷小。
x→0 时的等价无穷小替换表（必背）：

| 当 x→0 时 | 等价于 |
| --- | --- |
| sinx | x |
| tanx | x |
| arcsinx | x |
| arctanx | x |
| 1 - cosx | x²/2 |
| ln(1+x) | x |
| e^x - 1 | x |
| (1+x)^a - 1 | a·x（a 为常数） |
| x - sinx | x³/6 |
| tanx - sinx | x³/2 |
| a^x - 1 | x·lna |

**【易错】**等价无穷小只能在乘除运算中整体替换，加减法里不能随便换！例如 lim(x→0) (sinx - x)/x³ 若把 sinx 直接换成 x 会得到 0，这是错的。
**【技巧】**看到 1-cosx 立刻想到 x²/2；看到 ln(1+x)、e^x-1 立刻想到 x；看到 x-sinx 立刻想到 x³/6。
### 1.6 两个重要极限
① lim(x→0) sinx/x = 1
② lim(x→∞) (1 + 1/x)^x = e
   等价形式：lim(t→0) (1+t)^(1/t) = e
**【重点】**第②个专门对付 1^∞ 型：把底数凑成 1 + 小量，把指数凑成小量的倒数。
### 1.7 洛必达法则
用来求 0/0 型或 ∞/∞ 型的极限：分子分母分别求导，再求极限。
若 lim f(x)/g(x) 是 0/0 型或 ∞/∞ 型，且 f、g 可导，则
lim f(x)/g(x) = lim f′(x)/g′(x)（右边极限存在时成立）
使用注意（三条铁律）：
- 必须是 0/0 或 ∞/∞ 型；其他型先变形（0·∞ 化为 0/0 或 ∞/∞，∞-∞ 先通分或有理化，1^∞、0^0、∞^0 先取对数）。
- 分子分母分别求导，不是用商的求导法则。
- 一次不行可以多次，但越求越复杂就要换方法（等价无穷小、泰勒展开等）。
**【技巧】**洛必达不是万能钥匙：先看能不能用等价无穷小简化，再考虑洛必达。
### 1.8 连续性与间断点
连续大白话：函数图像在这点没有断开，能一笔画过去。
f(x) 在 x₀ 处连续 ⇔ lim(x→x₀) f(x) = f(x₀)
即：左极限 = 右极限 = 函数值
不连续的点叫间断点，按性质分类：

| 类型 | 定义 | 典型例子 |
| --- | --- | --- |
| 可去间断点 | 左右极限存在且相等，但不等于函数值（或函数无定义） | y = sinx/x 在 x=0 处（极限为 1，函数无定义） |
| 跳跃间断点 | 左右极限都存在但不相等 | y = [x]（取整函数）在整数点 |
| 无穷间断点 | 至少一侧极限为无穷大 | y = 1/x 在 x=0 处 |
| 振荡间断点 | 极限不存在（来回振荡） | y = sin(1/x) 在 x=0 处 |

**【重点】**第一类间断点 = 可去 + 跳跃（左右极限都存在）；第二类间断点 = 无穷 + 振荡。
### 1.9 例题精讲（4 道）
#### 例题 1：0/0 型极限
【例 1】求极限 lim(x→0) (1 - cosx)/x²。
**【思路点拨】**0/0 型，分子出现 1-cosx，直接使用等价无穷小 1-cosx ~ x²/2。
解：
原式 = lim(x→0) (x²/2)/x²
     = 1/2
**【答案】1/2**
#### 例题 2：∞/∞ 型极限
【例 2】求极限 lim(x→∞) (3x² + 2x + 1)/(2x² - x + 5)。
**【思路点拨】**∞/∞ 型，分子分母同除以最高次幂 x²（抓大头：只看最高次项）。
解：分子分母同除以 x²
原式 = lim(x→∞) (3 + 2/x + 1/x²)/(2 - 1/x + 5/x²)
     = (3 + 0 + 0)/(2 - 0 + 0)
     = 3/2
**【答案】3/2**
#### 例题 3：1^∞ 型极限
【例 3】求极限 lim(x→∞) (1 + 1/x)^(2x)。
**【思路点拨】**1^∞ 型，套第二个重要极限：把指数 2x 拆成 2 乘 x，让 (1+1/x)^x 趋向 e。
解：原式 = [(1 + 1/x)^x]²
因为 lim(x→∞) (1 + 1/x)^x = e
所以原式 = e²
**【答案】e²**
#### 例题 4：含参讨论（连续）
【例 4】设 f(x) = sin3x/(2x)（x≠0），且 f(0) = a。问 a 取何值时 f(x) 在 x=0 处连续？
**【思路点拨】**连续 ⇔ lim(x→0) f(x) = f(0)。先求极限，再令极限值等于 a。
解：lim(x→0) sin3x/(2x)
    = lim(x→0) (3/2)·(sin3x/(3x))
    = (3/2)·1 = 3/2
连续要求 lim(x→0) f(x) = f(0)
所以 a = 3/2
**【答案】a = 3/2**
**【重点】**本章小结：极限三大工具——等价无穷小、两个重要极限、洛必达；先判断型，再选工具。
## 第 2 章 一元函数微分学
### 2.1 导数定义与几何意义
大白话：导数就是函数在某一点的瞬时变化率，几何上就是曲线在这点的切线斜率。
f′(x₀) = lim(Δx→0) [f(x₀+Δx) - f(x₀)]/Δx
等价写法：f′(x₀) = lim(x→x₀) [f(x) - f(x₀)]/(x - x₀)
切线方程：曲线 y = f(x) 在点 (x₀, f(x₀)) 处的切线为
y - f(x₀) = f′(x₀)·(x - x₀)
**【技巧】**看到差商取极限的式子就要想到导数定义，选择题常考凑形式。
### 2.2 可导与连续的关系
可导 ⇒ 连续；连续 不一定 可导
例子：y = |x| 在 x = 0 处连续（图像不断），但左导数 -1、右导数 1，不相等，所以不可导（图像有个尖角）。
**【易错】**判断在某点可导必须用定义：左导数 = 右导数，不能只算一边。
### 2.3 基本求导公式表（必背）

| 函数 | 导数 | 函数 | 导数 |
| --- | --- | --- | --- |
| C（常数） | 0 | tanx | sec²x |
| x^a | a·x^(a-1) | cotx | -csc²x |
| sinx | cosx | secx | secx·tanx |
| cosx | -sinx | cscx | -cscx·cotx |
| e^x | e^x | lnx | 1/x |
| a^x | a^x·lna | log_a(x) | 1/(x·lna) |
| arcsinx | 1/√(1-x²) | arccosx | -1/√(1-x²) |
| arctanx | 1/(1+x²) | arccotx | -1/(1+x²) |

**【重点】**e^x 求导还是 e^x，lnx 求导是 1/x，这两个出现频率最高，先背熟。
### 2.4 四则运算与链式法则
(u ± v)′ = u′ ± v′
(u·v)′ = u′v + uv′
(u/v)′ = (u′v - uv′)/v²
复合函数链式法则：[f(g(x))]′ = f′(g(x))·g′(x)
口诀：外层求导，再乘内层导数
**【重点】**链式法则是求导的灵魂：e^(x²)、sin(2x+1)、ln(x²+1) 全是外层求导 × 内层导数。
### 2.5 隐函数求导
由方程 F(x, y) = 0 确定 y 是 x 的函数时，把方程两边同时对 x 求导，遇到 y 就乘 y′，再解出 y′。
例：x² + y² = 1 两边求导：2x + 2y·y′ = 0 ⇒ y′ = -x/y
**【技巧】**记住口诀：方程两边同时对 x 求导，见到 y 就补一个 y′。
### 2.6 参数方程求导
x = φ(t)，y = ψ(t) 时
dy/dx = (dy/dt)/(dx/dt) = ψ′(t)/φ′(t)（φ′(t) ≠ 0）
### 2.7 对数求导法
适合幂指函数（底数和指数都有 x）以及连乘连除的形式：两边取对数，再用隐函数求导。
例：y = x^x ⇒ lny = x·lnx ⇒ y′/y = lnx + 1 ⇒ y′ = x^x·(lnx + 1)
**【技巧】**看到底数指数都含 x（如 x^x、x^(sinx)）必用对数求导法。
### 2.8 微分
大白话：自变量变化一点点 dx 时，函数值变化量的线性近似。
dy = f′(x)·dx
**【提示】**会求导就会求微分：先求导，再乘 dx。
### 2.9 三大中值定理

| 定理 | 条件 | 结论 | 主要用途 |
| --- | --- | --- | --- |
| 罗尔定理 | f 在 [a,b] 连续，在 (a,b) 可导，且 f(a) = f(b) | ∃ξ∈(a,b)，使 f′(ξ) = 0 | 证明存在一点导数为 0 |
| 拉格朗日定理 | f 在 [a,b] 连续，在 (a,b) 可导 | ∃ξ∈(a,b)，使 f(b)-f(a) = f′(ξ)(b-a) | 证明不等式、恒等式 |
| 柯西定理 | f、g 连续可导，且 g′(x) ≠ 0 | ∃ξ，使 [f(b)-f(a)]/[g(b)-g(a)] = f′(ξ)/g′(ξ) | 证明更一般的结论 |

**【重点】**罗尔定理是基础：很多证明题要先构造一个辅助函数 F(x)，使 F(a)=F(b)，再用罗尔。
### 2.10 泰勒公式与常用麦克劳林展开
大白话：用一个多项式去近似一个复杂的函数，在展开点附近误差很小。
f(x) = f(x₀) + f′(x₀)(x-x₀) + f″(x₀)/2!·(x-x₀)² + … + f⁽ⁿ⁾(x₀)/n!·(x-x₀)ⁿ + 余项
常用麦克劳林展开（x₀ = 0，务必背）：
e^x = 1 + x + x²/2! + x³/3! + x⁴/4! + …
sinx = x - x³/3! + x⁵/5! - x⁷/7! + …
cosx = 1 - x²/2! + x⁴/4! - x⁶/6! + …
ln(1+x) = x - x²/2 + x³/3 - x⁴/4 + …（|x|<1）
1/(1-x) = 1 + x + x² + x³ + …（|x|<1）
(1+x)^a = 1 + ax + a(a-1)/2!·x² + …
**【技巧】**求极限时等价无穷小不够用，就展开到分子分母的最低阶；e^x 和 sinx 的展开最常用。
### 2.11 单调性、极值与凹凸性
单调性：在区间内 f′>0 单调递增，f′<0 单调递减。
极值点：只可能是驻点（f′=0）或不可导点，再用充分条件判断。
第一充分条件：x₀ 两侧 f′ 左正右负 ⇒ 极大值；左负右正 ⇒ 极小值
第二充分条件：f′(x₀)=0 时，f″(x₀)<0 ⇒ 极大值；f″(x₀)>0 ⇒ 极小值
凹凸性：f″>0 凹（开口向上），f″<0 凸（开口向下）；凹凸性改变的点叫拐点。
**【易错】**极值点处导数不一定为 0（如 |x| 在 0 处）；驻点也不一定是极值点（如 y=x³ 在 0 处）。
### 2.12 最值应用
闭区间上连续函数的最值：比较区间内所有驻点、不可导点和两个端点的函数值，取最大、最小。
实际应用题（最大容积、最短距离等）的套路：
- 设自变量 x 和目标函数 y（先弄清哪个变量在变）。
- 列出函数关系式，并写出 x 的取值范围（定义域）。
- 求导找驻点，结合端点与边界判断最值。
### 2.13 例题精讲（4 道）
#### 例题 1：用定义求导数
【例 1】用导数定义求 f(x) = x² 在 x = 1 处的导数。
**【思路点拨】**套导数定义式，把差商化简后再取极限。
解：f′(1) = lim(Δx→0) [f(1+Δx) - f(1)]/Δx
     = lim(Δx→0) [(1+Δx)² - 1]/Δx
     = lim(Δx→0) (2Δx + Δx²)/Δx
     = lim(Δx→0) (2 + Δx)
     = 2
**【答案】f′(1) = 2**
#### 例题 2：复合函数求导
【例 2】设 y = ln(x² + 1)，求 dy/dx。
**【思路点拨】**复合函数：外层 ln 求导得 1/(x²+1)，再乘内层 (x²+1) 的导数 2x。
解：dy/dx = [1/(x²+1)]·(x²+1)′
         = [1/(x²+1)]·2x
         = 2x/(x²+1)
**【答案】dy/dx = 2x/(x²+1)**
#### 例题 3：对数求导法
【例 3】设 y = x^x（x > 0），求 dy/dx。
**【思路点拨】**底数和指数都含 x，是幂指函数，两边取对数再用隐函数求导。
解：两边取对数：lny = x·lnx
两边对 x 求导：y′/y = lnx + x·(1/x) = lnx + 1
所以 y′ = y·(lnx + 1) = x^x·(lnx + 1)
**【答案】dy/dx = x^x·(lnx + 1)**
#### 例题 4：中值定理证明题
【例 4】设 a < b，证明：存在 ξ∈(a,b)，使得 e^b - e^a = e^ξ·(b - a)。
**【思路点拨】**结论的形式正是拉格朗日中值定理 f(b)-f(a) = f′(ξ)(b-a)，取 f(x) = e^x 直接套。
证明：令 f(x) = e^x，则 f 在 [a,b] 连续、在 (a,b) 可导。
由拉格朗日中值定理，∃ξ∈(a,b)，使
f(b) - f(a) = f′(ξ)·(b - a)
即 e^b - e^a = e^ξ·(b - a)，命题得证。
**【答案】证毕（拉格朗日中值定理的直接应用）**
**【重点】**本章小结：求导四板斧——公式、四则、链式、隐函数/对数；证明题先想三个中值定理。
## 第 3 章 一元函数积分学
### 3.1 不定积分概念
大白话：不定积分是求导的逆运算——谁的导数是 f(x)，谁就是 f(x) 的原函数。
∫f(x)dx = F(x) + C，其中 F′(x) = f(x)
**【易错】**千万别漏掉积分常数 C！不定积分是一族函数，不是某一个函数。
### 3.2 基本积分表（必背）

| 积分 | 结果 | 积分 | 结果 |
| --- | --- | --- | --- |
| ∫x^a dx | x^(a+1)/(a+1) + C（a≠-1） | ∫1/x dx | ln|x| + C |
| ∫sinx dx | -cosx + C | ∫cosx dx | sinx + C |
| ∫sec²x dx | tanx + C | ∫csc²x dx | -cotx + C |
| ∫e^x dx | e^x + C | ∫a^x dx | a^x/lna + C |
| ∫1/(1+x²) dx | arctanx + C | ∫1/√(1-x²) dx | arcsinx + C |
| ∫secx·tanx dx | secx + C | ∫cscx·cotx dx | -cscx + C |

**【重点】**∫1/x dx = ln|x| + C 必须带绝对值，这是最容易丢分的地方。
### 3.3 第一类换元法（凑微分）
大白话：把被积表达式凑成某个函数的微分形式，然后整体换元。
∫f(φ(x))·φ′(x)dx = ∫f(u)du，其中 u = φ(x)
常见凑微分套路：
- ∫f(ax+b)dx：凑 d(ax+b)，如 ∫e^(2x+1)dx = (1/2)e^(2x+1) + C
- ∫x·f(x²)dx：凑 d(x²)，如 ∫x·e^(x²)dx
- ∫f(e^x)·e^x dx：凑 d(e^x)
- ∫f(lnx)/x dx：凑 d(lnx)
**【技巧】**凑微分的本质就是倒着用链式法则：看到 x dx 就想到 (1/2)d(x²)。
### 3.4 第二类换元法（三角代换）
遇到根号下的平方和差，用三角代换把根号去掉：

| 被积表达式 | 代换 | 化简结果 |
| --- | --- | --- |
| √(a² - x²) | x = a·sint | a·cost |
| √(a² + x²) | x = a·tant | a·sect |
| √(x² - a²) | x = a·sect | a·tant |

**【技巧】**出现 √(a²-x²) 就令 x = a·sint；出现 x²+a² 就令 x = a·tant；代换后记得回代。
### 3.5 分部积分法
∫u dv = uv - ∫v du
口诀反对幂指三：选 u 的顺序是 反三角函数 → 对数函数 → 幂函数 → 指数函数 → 三角函数，越靠前越优先当 u。
**【重点】**出现 lnx、arctanx 就让它当 u（因为好求导）；出现 e^x、sinx、cosx 就让它们进 dv（因为好积分）。
### 3.6 定积分概念与重要性质
大白话：定积分就是曲边梯形的面积（有正负），记作 ∫[a,b] f(x)dx。
重要性质：
- 区间可加：∫[a,b] f dx = ∫[a,c] f dx + ∫[c,b] f dx
- 奇偶性：f 为奇函数 ⇒ ∫[-a,a] f dx = 0；f 为偶函数 ⇒ ∫[-a,a] f dx = 2∫[0,a] f dx
- 积分中值定理：∃ξ∈[a,b]，使 ∫[a,b] f(x)dx = f(ξ)(b-a)
**【技巧】**对称区间先看奇偶性：奇函数直接得 0，能省一大半计算。
### 3.7 牛顿-莱布尼茨公式
∫[a,b] f(x)dx = F(b) - F(a)，其中 F′(x) = f(x)
使用步骤：先求原函数 F(x)，再把上限 b 代入减下限 a 代入。
### 3.8 变上限积分求导
d/dx ∫[a, x] f(t)dt = f(x)
d/dx ∫[φ(x), ψ(x)] f(t)dt = f(ψ(x))·ψ′(x) - f(φ(x))·φ′(x)
**【重点】**上限是函数就乘它的导数；下限是函数要变号。把被积函数里的 t 换成上限再乘上限导数，减去换下限。
### 3.9 反常积分判敛
反常积分两类：无穷区间（上限或下限为 ∞）与瑕积分（被积函数在某点无界）。
常用判敛工具：
- p-积分（无穷区间）：∫[1,∞] 1/x^p dx，p>1 收敛，p≤1 发散。
- p-积分（瑕积分）：∫[0,1] 1/x^p dx，p<1 收敛，p≥1 发散。
- 比较判别法：与已知敛散的积分比较大小。
**【易错】**反常积分先判断敛散再计算；直接代上下限可能算出荒谬结果。
### 3.10 定积分的应用
平面图形面积：两条曲线 y=f(x)、y=g(x) 围成的区域面积
S = ∫[a,b] |f(x) - g(x)| dx
旋转体体积：曲线 y=f(x)（f≥0）绕 x 轴旋转一周所得体积
V = π∫[a,b] [f(x)]² dx
**【技巧】**求面积先画图，确定上减下和交点；求旋转体体积记住 π 乘半径平方的积分。
### 3.11 例题精讲（4 道）
#### 例题 1：凑微分
【例 1】求不定积分 ∫x·e^(x²) dx。
**【思路点拨】**x dx 正好是 (1/2)d(x²)，凑微分后整体换元 u = x²。
解：∫x·e^(x²)dx = (1/2)∫e^(x²)d(x²)
    令 u = x²，原式 = (1/2)∫e^u du = (1/2)e^u + C
    回代：= (1/2)e^(x²) + C
**【答案】(1/2)e^(x²) + C**
#### 例题 2：分部积分
【例 2】求不定积分 ∫x·e^x dx。
**【思路点拨】**反对幂指三：幂函数 x 当 u，e^x dx 当 dv。
解：令 u = x，dv = e^x dx，则 du = dx，v = e^x
∫x·e^x dx = x·e^x - ∫e^x dx
          = x·e^x - e^x + C
          = (x - 1)e^x + C
**【答案】(x - 1)e^x + C**
#### 例题 3：对称区间上的定积分（奇偶性）
【例 3】计算定积分 ∫[-1,1] (x³ + cosx) dx。
**【思路点拨】**对称区间 [-1,1]：x³ 是奇函数积分为 0，cosx 是偶函数翻倍。
解：∫[-1,1] x³ dx = 0（奇函数）
∫[-1,1] cosx dx = 2∫[0,1] cosx dx = 2·sinx|[0,1] = 2sin1
原式 = 0 + 2sin1
**【答案】2sin1**
#### 例题 4：变上限积分求导
【例 4】设 F(x) = ∫[0, x²] sin(t²) dt，求 F′(x)。
**【思路点拨】**变上限积分求导公式：被积函数把 t 换成上限 x²，再乘上限的导数 2x。
解：F′(x) = sin((x²)²)·(x²)′
        = sin(x⁴)·2x
        = 2x·sin(x⁴)
**【答案】F′(x) = 2x·sin(x⁴)**
**【重点】**本章小结：不定积分三把刀——凑微分、三角代换、分部积分；定积分牢记牛顿-莱布尼茨公式与奇偶性。
## 第 4 章 微分方程
### 4.1 基本概念
微分方程：含有未知函数导数的方程。
- 阶：方程中最高阶导数的阶数。如 y″ + y = 0 是二阶。
- 通解：含有任意常数的解；n 阶方程的通解含 n 个任意常数。
- 特解：给定初始条件（如 y(0)=1）后，把常数定下来得到的解。
例：y′ = 2x 的通解是 y = x² + C；若 y(0) = 1，则特解 y = x² + 1
### 4.2 一阶可分离变量方程
形式：dy/dx = g(x)·h(y)。解法：把 x、y 分到等式两边，各自积分。
dy/dx = g(x)·h(y) ⇒ ∫dy/h(y) = ∫g(x)dx（h(y) ≠ 0）
### 4.3 一阶齐次方程
形式：dy/dx = f(y/x)。解法：令 u = y/x，化为可分离变量方程。
令 u = y/x，则 y = ux，dy/dx = u + x·du/dx
代入得：u + x·du/dx = f(u)，化为可分离变量
### 4.4 一阶线性微分方程（重点）
形式：y′ + P(x)y = Q(x)。通解公式（直接背）：
y = e^(-∫P(x)dx) · [ ∫Q(x)·e^(∫P(x)dx) dx + C ]
使用步骤：
- 先化成标准形式 y′ + P(x)y = Q(x)。
- 求出积分因子 e^(∫P(x)dx)。
- 套公式，最后别忘了常数 C。
**【易错】**公式里第一个因子带负号 e^(-∫Pdx)，第二个不带；两个积分号都要写全。
### 4.5 二阶常系数齐次线性方程
形式：y″ + py′ + qy = 0。解法：特征根法。
特征方程：r² + pr + q = 0
按特征根分三种情况写通解：

| 特征根情况 | 通解形式 |
| --- | --- |
| 两个不等实根 r₁ ≠ r₂ | y = C₁e^(r₁x) + C₂e^(r₂x) |
| 二重实根 r₁ = r₂ = r | y = (C₁ + C₂x)·e^(rx) |
| 共轭复根 r = α ± βi | y = e^(αx)·(C₁cosβx + C₂sinβx) |

### 4.6 二阶常系数非齐次线性方程
形式：y″ + py′ + qy = f(x)。核心结论：
通解 = 对应齐次方程的通解 + 非齐次方程的一个特解
特解形式表（针对两种常见 f(x)，直接设出形式再代回定系数）：

| f(x) 类型 | 设特解形式 | 说明 |
| --- | --- | --- |
| f(x) = Pₙ(x)·e^(λx)（多项式乘指数） | y* = x^k·Qₙ(x)·e^(λx) | k = λ 作为特征根的重复次数（0、1 或 2） |
| f(x) = e^(λx)·(Acos(ωx) + Bsin(ωx)) | y* = x^k·e^(λx)·(Ccos(ωx) + Dsin(ωx)) | k = λ±iω 是否为特征根的次数（0 或 1） |

**【重点】**非齐次方程的核心动作是设特解：设好形式后代入原方程，比较系数求出未知常数。
### 4.7 例题精讲（3 道）
#### 例题 1：可分离变量
【例 1】求微分方程 dy/dx = 2xy 的通解。
**【思路点拨】**可分离变量：y 和 dy 放一边，x 和 dx 放一边，两边积分。
解：dy/y = 2x dx
两边积分：∫dy/y = ∫2x dx
ln|y| = x² + C₁
y = ±e^(x² + C₁) = C·e^(x²)（C 为任意常数）
**【答案】y = C·e^(x²)**
#### 例题 2：一阶线性方程（公式法）
【例 2】求微分方程 y′ + y = e^(-x) 的通解。
**【思路点拨】**标准形式 y′+P(x)y=Q(x)，这里 P=1、Q=e^(-x)，直接套通解公式。
解：P(x) = 1，Q(x) = e^(-x)
∫P dx = x，积分因子 e^(∫P dx) = e^x
y = e^(-x)·[ ∫e^(-x)·e^x dx + C ]
  = e^(-x)·[ ∫1 dx + C ]
  = e^(-x)·(x + C)
**【答案】y = (x + C)·e^(-x)**
#### 例题 3：二阶常系数齐次
【例 3】求微分方程 y″ - 3y′ + 2y = 0 的通解。
**【思路点拨】**写特征方程，解出两个不等实根，直接套第一种通解形式。
解：特征方程 r² - 3r + 2 = 0
(r - 1)(r - 2) = 0 ⇒ r₁ = 1，r₂ = 2
两个不等实根 ⇒ y = C₁e^x + C₂e^(2x)
**【答案】y = C₁e^x + C₂e^(2x)**
**【重点】**本章小结：一阶三类（可分离、齐次、线性公式）；二阶齐次用特征根法，非齐次=齐次通解+特解。
## 第 5 章 多元函数微分学
### 5.1 偏导数
大白话：二元函数有两个变量，偏导数就是只动一个变量、把另一个当常数求导。
∂z/∂x：把 y 当常数，对 x 求导
∂z/∂y：把 x 当常数，对 y 求导
**【技巧】**求偏导时，把不动的变量当成数字处理，例如对 x 求偏导时 y² 就是常数。
### 5.2 全微分
dz = (∂z/∂x)·dx + (∂z/∂y)·dy
**【提示】**可微 ⇒ 连续、偏导存在；但偏导存在不一定可微（考研主要考计算，记住公式即可）。
### 5.3 链式法则
复合函数 z = f(u,v)，u = u(x,y)，v = v(x,y)：
∂z/∂x = ∂z/∂u·∂u/∂x + ∂z/∂v·∂v/∂x
∂z/∂y = ∂z/∂u·∂u/∂y + ∂z/∂v·∂v/∂y
**【技巧】**沿路径求导：数一数从 z 到 x 有几条路，每条路导数相乘，再把各条路相加。
### 5.4 隐函数求导
由方程 F(x, y) = 0 确定的隐函数 y = y(x)：
dy/dx = -F_x/F_y（F_y ≠ 0）
由方程 F(x, y, z) = 0 确定的隐函数 z = z(x,y)：
∂z/∂x = -F_x/F_z，∂z/∂y = -F_y/F_z
**【易错】**分子是对要求的变量求偏导，分母是对隐函数求偏导，前面记得加负号。
### 5.5 方向导数与梯度
方向导数：∂f/∂l = f_x·cosα + f_y·cosβ（α、β 是方向 l 的方向角）
梯度：grad f = (∂f/∂x, ∂f/∂y)
**【重点】**梯度方向是函数增长最快的方向，梯度的模就是最大方向导数。
### 5.6 二元函数极值（无条件）
步骤：求驻点 → 二阶判别。
① 解方程组 f_x = 0，f_y = 0，得驻点 (x₀, y₀)
② 在驻点处计算 A = f_xx，B = f_xy，C = f_yy
③ 判别：
   AC - B² > 0 且 A < 0 ⇒ 极大值
   AC - B² > 0 且 A > 0 ⇒ 极小值
   AC - B² < 0 ⇒ 不是极值（鞍点）
   AC - B² = 0 ⇒ 需用其他方法判断
**【易错】**别把顺序记错：A = f_xx（对 x 求两次），B = f_xy（先 x 后 y），C = f_yy。
### 5.7 条件极值与拉格朗日乘数法
求 f(x,y) 在约束条件 g(x,y) = 0 下的极值：
构造拉格朗日函数：L(x, y, λ) = f(x, y) + λ·g(x, y)
解方程组：L_x = 0，L_y = 0，L_λ = 0
得到候选点，再比较函数值大小
**【技巧】**实际应用题（围最大面积、造最省材料）先列目标函数和约束，再拉格朗日。
### 5.8 例题精讲（3 道）
#### 例题 1：偏导数与全微分
【例 1】设 z = x²y + sin(xy)，求 ∂z/∂x、∂z/∂y 及全微分 dz。
**【思路点拨】**把另一个变量当常数分别求偏导，再按 dz 的公式组合。
解：∂z/∂x = 2xy + y·cos(xy)
∂z/∂y = x² + x·cos(xy)
dz = [2xy + y·cos(xy)]dx + [x² + x·cos(xy)]dy
**【答案】∂z/∂x = 2xy + y·cos(xy)；∂z/∂y = x² + x·cos(xy)**
#### 例题 2：隐函数求导
【例 2】设 x² + y² = 1 确定隐函数 y = y(x)，求 dy/dx。
**【思路点拨】**令 F(x,y) = x² + y² - 1，用公式 dy/dx = -F_x/F_y。
解：令 F(x, y) = x² + y² - 1
F_x = 2x，F_y = 2y
dy/dx = -F_x/F_y = -2x/(2y) = -x/y
**【答案】dy/dx = -x/y**
#### 例题 3：二元函数极值
【例 3】求函数 f(x,y) = x² + y² - 2x - 4y + 5 的极值。
**【思路点拨】**先求驻点，再用 AC - B² 判别。
解：f_x = 2x - 2 = 0 ⇒ x = 1
f_y = 2y - 4 = 0 ⇒ y = 2
驻点 (1, 2)
A = f_xx = 2，B = f_xy = 0，C = f_yy = 2
AC - B² = 4 > 0 且 A = 2 > 0 ⇒ 极小值
f(1, 2) = 1 + 4 - 2 - 8 + 5 = 0
**【答案】极小值 0，在点 (1, 2) 处取得**
**【重点】**本章小结：偏导就是逐个变量求导；极值三步走——驻点、AC-B² 判别、比大小。
## 第 6 章 二重积分
### 6.1 概念与几何意义
大白话：二重积分就是曲顶柱体的体积，可以理解为底面积 × 平均高度。
∬D f(x,y) dxdy
### 6.2 直角坐标：X 型与 Y 型
X 型（先 y 后 x）：区域上下由两条曲线夹住，x 的范围固定。
∬D f dxdy = ∫[a,b] dx ∫[y₁(x), y₂(x)] f(x,y) dy
Y 型（先 x 后 y）：区域左右由两条曲线夹住，y 的范围固定。
∬D f dxdy = ∫[c,d] dy ∫[x₁(y), x₂(y)] f(x,y) dx
**【技巧】**选积分次序的原则：让内层积分好算（能求出原函数），区域描述尽量简单。
### 6.3 极坐标
什么时候用极坐标：被积函数出现 x² + y²，或者积分区域是圆、圆环、扇形。
x = r·cosθ，y = r·sinθ，dxdy = r·dr·dθ
∬D f(x,y)dxdy = ∫[α,β] dθ ∫[r₁(θ), r₂(θ)] f(rcosθ, rsinθ)·r dr
**【易错】**极坐标下 dxdy 要变成 r·dr·dθ，那个 r 千万不能漏！
### 6.4 交换积分次序
步骤：
- 由原积分限画出积分区域 D。
- 按新次序（X 型或 Y 型）重新描述区域。
- 写出新的上下限，注意变量对应关系。
**【重点】**交换次序的关键是画图，画对区域才能写对上下限。
### 6.5 例题精讲（3 道）
#### 例题 1：直角坐标
【例 1】计算二重积分 ∬D (x + y) dxdy，其中 D 由 x=0、x=1、y=0、y=x 围成。
**【思路点拨】**画图后用 X 型：0 ≤ x ≤ 1，0 ≤ y ≤ x。
解：原式 = ∫[0,1] dx ∫[0,x] (x + y) dy
内层：∫[0,x] (x+y)dy = (xy + y²/2)|[0,x] = x² + x²/2 = 3x²/2
原式 = ∫[0,1] (3x²/2) dx = (x³/2)|[0,1] = 1/2
**【答案】1/2**
#### 例题 2：极坐标
【例 2】计算二重积分 ∬D e^(x²+y²) dxdy，其中 D 为圆盘 x²+y² ≤ 1。
**【思路点拨】**被积函数出现 x²+y² 且区域是圆，用极坐标，e^(x²+y²) 变成 e^(r²)。
解：极坐标：0 ≤ θ ≤ 2π，0 ≤ r ≤ 1
原式 = ∫[0,2π] dθ ∫[0,1] e^(r²)·r dr
     = 2π·(1/2)·e^(r²)|[0,1]
     = π·(e - 1)
**【答案】π(e - 1)**
#### 例题 3：交换积分次序
【例 3】交换积分次序：∫[0,1] dx ∫[x,1] f(x,y) dy。
**【思路点拨】**画出区域：0 ≤ x ≤ 1，x ≤ y ≤ 1，是三角形；改写成 Y 型。
解：区域 D：0 ≤ x ≤ y ≤ 1
即 0 ≤ y ≤ 1，0 ≤ x ≤ y
交换后：∫[0,1] dy ∫[0,y] f(x,y) dx
**【答案】∫[0,1] dy ∫[0,y] f(x,y) dx**
**【重点】**本章小结：直角坐标选次序、极坐标记得乘 r、交换次序先画图，三大口诀记牢。
## 第 7 章 无穷级数（数学一）
### 7.1 基本概念
无穷级数就是无穷多项相加。部分和 Sₙ 的极限存在，就说级数收敛。
Σ(n=1→∞) aₙ，Sₙ = a₁ + a₂ + … + aₙ
若 lim(n→∞) Sₙ = S 存在，则级数收敛，和为 S
**【易错】**通项不趋于 0 的级数必发散（这是收敛的必要条件，选择题常考）。
### 7.2 正项级数判别法

| 判别法 | 内容 | 适用场合 |
| --- | --- | --- |
| 比较判别法 | 若 aₙ ≤ bₙ 且 Σbₙ 收敛，则 Σaₙ 收敛；若 Σbₙ 发散，则 Σaₙ 发散 | 能看出大小关系 |
| 比较极限形式 | lim aₙ/bₙ = c（0<c<∞），则 Σaₙ 与 Σbₙ 同敛散 | 与 p 级数比较 |
| 比值判别法 | lim aₙ₊₁/aₙ = ρ：ρ<1 收敛，ρ>1 发散，ρ=1 失效 | 含阶乘、指数 |
| 根值判别法 | lim ⁿ√aₙ = ρ：ρ<1 收敛，ρ>1 发散，ρ=1 失效 | 含 n 次方 |

**【重点】**p 级数 Σ1/n^p：p>1 收敛，p≤1 发散（p=1 就是调和级数，发散，常作比较标准）。
### 7.3 交错级数与莱布尼茨判别法
形如 Σ(-1)ⁿ·aₙ（aₙ>0）的级数叫交错级数。
莱布尼茨判别法：若 ① aₙ 单调递减（aₙ ≥ aₙ₊₁） ② lim aₙ = 0
则交错级数收敛
### 7.4 绝对收敛与条件收敛
Σ|aₙ| 收敛 ⇒ Σaₙ 绝对收敛
Σaₙ 收敛但 Σ|aₙ| 发散 ⇒ Σaₙ 条件收敛
**【重点】**绝对收敛 ⇒ 收敛；反过来不成立，如 Σ(-1)ⁿ/n 条件收敛。
### 7.5 幂级数
形式：Σ aₙxⁿ。收敛半径 R 的求法：
比值法：R = lim |aₙ/aₙ₊₁|
根值法：R = 1 / lim ⁿ√|aₙ|
**【易错】**求收敛域时，x = ±R 两个端点要单独代入级数判断敛散。
### 7.6 函数展开成幂级数（必背）
e^x = Σ(n=0→∞) xⁿ/n!，|x|<∞
sinx = Σ(n=0→∞) (-1)ⁿx^(2n+1)/(2n+1)!，|x|<∞
cosx = Σ(n=0→∞) (-1)ⁿx^(2n)/(2n)!，|x|<∞
1/(1-x) = Σ(n=0→∞) xⁿ，|x|<1
ln(1+x) = Σ(n=1→∞) (-1)^(n+1)xⁿ/n，|x|<1
### 7.7 傅里叶级数（概念了解）
大白话：把周期函数分解成一系列正弦、余弦的叠加。
f(x) ~ a₀/2 + Σ[aₙcos(nx) + bₙsin(nx)]
**【提示】**数学一主要考概念与系数公式的记忆，一般不会要求完整计算。
### 7.8 例题精讲（3 道）
#### 例题 1：正项级数（比值法）
【例 1】判别级数 Σ(n=1→∞) n!/nⁿ 的敛散性。
**【思路点拨】**通项含阶乘，用比值判别法。
解：aₙ = n!/nⁿ
aₙ₊₁/aₙ = [(n+1)!/(n+1)^(n+1)]·[nⁿ/n!]
        = (n+1)·nⁿ/(n+1)^(n+1)
        = [n/(n+1)]ⁿ
lim aₙ₊₁/aₙ = lim [n/(n+1)]ⁿ = 1/e < 1 ⇒ 收敛
**【答案】级数收敛**
#### 例题 2：交错级数
【例 2】判别级数 Σ(n=1→∞) (-1)ⁿ/n 的敛散性，并说明是绝对收敛还是条件收敛。
**【思路点拨】**先看绝对值级数（调和级数发散），再用莱布尼茨判别交错级数本身。
解：Σ|(-1)ⁿ/n| = Σ1/n 发散（调和级数）
原级数是交错级数：aₙ = 1/n 单调递减且趋于 0
由莱布尼茨判别法，原级数收敛
收敛但绝对值级数发散 ⇒ 条件收敛
**【答案】条件收敛**
#### 例题 3：幂级数收敛半径
【例 3】求幂级数 Σ(n=1→∞) xⁿ/n 的收敛半径与收敛域。
**【思路点拨】**用比值公式求 R，再单独检验 x = ±1 两个端点。
解：aₙ = 1/n
R = lim |aₙ/aₙ₊₁| = lim (1/n)/(1/(n+1)) = lim (n+1)/n = 1
x = 1 时：Σ1/n 发散
x = -1 时：Σ(-1)ⁿ/n 条件收敛
收敛域：[-1, 1)
**【答案】R = 1，收敛域为 [-1, 1)**
**【重点】**本章小结：判敛先看通项是否趋于 0，正项用比较/比值/根值，交错用莱布尼茨，幂级数背展开式。
## 第 8 章 空间解析几何（数学一概要）
### 8.1 向量运算
- 点积（数量积）：a·b = |a||b|cosθ；a⊥b ⇔ a·b = 0。用于求夹角、判断垂直。
- 叉积（向量积）：a×b 是同时垂直于 a、b 的向量；|a×b| = |a||b|sinθ。用于求平行四边形面积、平面法向量。
- 混合积：(a×b)·c。用于判断三向量是否共面、求平行六面体体积。
a·b = a₁b₁ + a₂b₂ + a₃b₃
a×b = (a₂b₃-a₃b₂, a₃b₁-a₁b₃, a₁b₂-a₂b₁)
### 8.2 平面与直线方程

| 对象 | 方程形式 | 说明 |
| --- | --- | --- |
| 平面（点法式） | A(x-x₀) + B(y-y₀) + C(z-z₀) = 0 | (A,B,C) 是法向量 |
| 平面（一般式） | Ax + By + Cz + D = 0 | 最常用 |
| 直线（点向式） | (x-x₀)/m = (y-y₀)/n = (z-z₀)/p | (m,n,p) 是方向向量 |
| 直线（参数式） | x = x₀+mt，y = y₀+nt，z = z₀+pt | t 为参数 |

### 8.3 常见曲面

| 曲面 | 方程 | 形状描述 |
| --- | --- | --- |
| 球面 | x² + y² + z² = R² | 篮球 |
| 圆柱面 | x² + y² = R² | 水管 |
| 椭球面 | x²/a² + y²/b² + z²/c² = 1 | 压扁的球 |
| 旋转抛物面 | z = x² + y² | 碗 |
| 锥面 | z² = x² + y² | 尖帽子 |
| 双曲抛物面 | z = x² - y² | 马鞍面 |

## 第 9 章 三重积分与曲线曲面积分（数学一概要）
### 9.1 三重积分
大白话：三重积分 = 空间物体的质量（密度 × 体积）。
直角坐标：∭Ω f(x,y,z) dV = ∫dx ∫dy ∫f dz
柱坐标：x = rcosθ，y = rsinθ，z = z，dV = r·dr·dθ·dz
球坐标：x = ρsinφcosθ，y = ρsinφsinθ，z = ρcosφ，dV = ρ²sinφ·dρ·dφ·dθ
**【技巧】**圆柱、圆锥区域用柱坐标；球区域用球坐标；dV 的因子（r 或 ρ²sinφ）千万别漏。
### 9.2 两类曲线积分

| 类型 | 记号 | 计算方法 | 意义 |
| --- | --- | --- | --- |
| 第一类（对弧长） | ∫L f ds | 参数化后 ds = √(x′²+y′²)dt 代入 | 曲线质量（与方向无关） |
| 第二类（对坐标） | ∫L P dx + Q dy | 参数化后代入 dx、dy | 变力做功（与方向有关） |

### 9.3 两类曲面积分

| 类型 | 记号 | 计算方法 | 意义 |
| --- | --- | --- | --- |
| 第一类（对面积） | ∬Σ f dS | 投影到坐标面：dS = √(1+z_x²+z_y²)dxdy | 曲面质量 |
| 第二类（对坐标） | ∬Σ P dydz + Q dzdx + R dxdy | 分面投影计算，注意方向正负号 | 流量 |

### 9.4 三大公式（一句话总结）

| 公式 | 一句话总结 | 适用场景 |
| --- | --- | --- |
| 格林公式 | ∮L Pdx+Qdy = ∬D (∂Q/∂x - ∂P/∂y) dxdy | 平面闭曲线 ⇄ 二重积分 |
| 高斯公式 | ∬Σ Pdydz+Qdzdx+Rdxdy = ∭Ω (∂P/∂x+∂Q/∂y+∂R/∂z) dV | 空间闭曲面 ⇄ 三重积分 |
| 斯托克斯公式 | ∮L Pdx+Qdy+Rdz = ∬Σ (rotF·n) dS | 空间闭曲线 ⇄ 曲面积分 |

**【重点】**用三大公式前先检查：曲线/曲面是否闭合、方向是否取正，不闭合要先补线补面。
