# 5G网络优化

> 科目：通信与信号 ｜ 类型：知识梳理（自整理，附免费课程链接）

## 是什么

网络优化（简称「网优」）——5G 网络建成运行后，通过**测试、分析、调整参数和站点**，让网络覆盖更好、速率更快、掉话更少。是通信行业里岗位量大、门槛相对友好的方向之一。

## 核心工作内容

- **覆盖优化**：解决弱覆盖、越区覆盖、覆盖空洞
- **容量优化**：小区忙闲不均、资源调度
- **干扰排查**：网内/网外干扰定位
- **切换优化**：小区间移动时保持连接不中断
- **KPI 指标监控**：接通率、掉话率、切换成功率、速率等

## 关键概念

| 概念 | 说明 |
| --- | --- |
| SSB | 同步信号块，终端用它搜索小区、测量信号 |
| RSRP | 参考信号接收功率，衡量「信号有多强」 |
| SINR | 信干噪比，衡量「信号有多干净」，比强度更关键 |
| 波束赋形 | 大规模天线（Massive MIMO）定向覆盖 |
| 切换 | 终端在不同小区间移动时保持连接 |

## 学习路径

1. 5G 空口与 NR 协议基础
2. 路测（DT/CQT）与数据分析
3. 参数优化与 KPI 指标
4. 专题优化（覆盖 / 干扰 / 速率 / 掉话）
