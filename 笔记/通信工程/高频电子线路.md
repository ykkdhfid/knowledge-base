# 高频电子线路

> 科目：通信工程 ｜ 收录日期：2026-08-17 ｜ 来源：知识123/通信工程知识库

> 高频（射频）电子线路是"通信原理的硬件实现"：发射机的末级、接收机的第一级都靠它。考研/面试高频考点：振荡器、混频器、锁相环。

---

## 一、知识地图

```
高频电子线路
├── 选频网络：LC谐振回路、耦合回路、固体滤波器（晶体/陶瓷/声表面）
├── 高频小信号放大：调谐放大器（增益+选台）
├── 高频功率放大：丙类功放、效率与导通角、负载匹配
├── 正弦波振荡器：三点式、晶体振荡器、频率稳定度
├── 混频：超外差结构、镜像频率
├── 调制解调电路：变容二极管调频、包络检波、鉴频
└── 锁相环 PLL：倍频/分频/频率合成、FM解调
```

---

## 二、选频网络（高频电路的"心脏")

LC 并联谐振回路：谐振频率 f₀ = 1/(2π√(LC))，谐振时阻抗最大、呈纯阻。

**品质因数** Q = 回路储能/每周期耗能 = ω₀L/r。

**通频带** B = f₀/Q → **Q 越大选择性越好但通带越窄**（鱼与熊掌，广播选台 vs 传数据要带宽）。

### 例题 1：中周选台

**题目**：收音机中频 465kHz，回路 Q=100。通频带多少？

**详解**：B = 465k/100 = **4.65kHz**（AM 信号带宽 9kHz 略超 → 实际 Q 选取要兼顾保真）。

### 例题 2：石英晶体为什么稳？

**题目**：晶振频率稳定度 10⁻⁶，10MHz 晶振一天漂多少？

**详解**：10⁷×10⁻⁶ = 10Hz/MHz→ 24h 漂约 **±10Hz**（普通 LC 只能做到 10⁻³~10⁻⁴）。晶体等效 Q 高达 10⁵+ 且物理参数稳 → 时钟基准都用它。温补(TCXO)/恒温(OCXO)再提 2~4 个数量级。

## 三、高频功率放大器（发射机的"大嗓门"）

按导通角分类：甲类 360°（线性差效率≤50%）、乙类 180°（78.5%）、**丙类 <180°（效率 80%+ 但需谐振回路"整形"还原正弦）**。

### 例题 3：丙类功放效率估算

**题目**：丙类功放电源 12V，集电极电流余弦脉冲峰值 1A，导通角 θ=60°，直流分量 I_C0 = i_cmax·α₀(60°)≈0.218A。求直流输入功率与效率量级。

**详解**：
1. P_dc = 12V × 0.218A ≈ 2.6W；
2. 基波分量 α₁(60°)≈0.391 → I_c1 ≈ 0.391A，输出功率 P_o = ½·I_c1·U_c（取 U_c≈11V）≈ 2.15W；
3. η ≈ 2.15/2.6 ≈ **83%**——效率高是因为"管子要么截止要么饱和"，损耗小。
> 手机功放（GSM 用 GMSK 恒包络）正是丙类；但 4G/5G 高峰均比信号必须回退到线性甲乙类+预失真（DPD）校正。

## 四、正弦波振荡器

**振荡条件（巴克豪森）**：|AF| ≥ 1 且相位 = 2π 的整数倍。起振 |AF|>1，稳幅靠非线性自动降到 =1。

**三点式口诀**："射同余异"——与发射极相连的两个电抗同性质、集基之间异性 → 满足则振。

### 例题 4：西勒/考毕兹判断

**题目**：电容三点式（考毕兹）：C1 接 c-e，C2 接 b-e，L 接 c-b。能振吗？频率？

**详解**：
1. 射极接 C1、C2（同为电容=同性质 ✓），c-b 间接电感（异性 ✓）→ **满足三点式，能振**；
2. f₀ = 1/(2π√(L·C1C2/(C1+C2)))。
3. 改进型"克拉泼/西勒"在 L 支路串小电容，使频率主要由小电容决定 → 减小管子极间电容影响，稳定度↑（FM 收音机本振就是西勒电路）。

## 五、超外差接收机（一百年不过时的架构）

```
天线→高频放大→混频器（与本振 f_LO 差拍）→中频放大（固定f_IF）→解调→音频
```

**精髓**：把任何电台都搬到**固定中频**再放大 → 中频放大器可做成高增益、稳定、统一规格（一手拿捏"增益"与"选择性"的矛盾）。

### 例题 5：镜像频率（超外差的代价）

**题目**：AM 收音机 f_IF=465kHz，本振 f_LO = f_RF+465k。接收 1000kHz 电台时镜像干扰频率？

**详解**：
1. f_LO = 1000+465 = 1465kHz；
2. 镜像 = f_LO + f_IF = 1465+465 = **1930kHz**（它混频后同样落在 465kHz，形成干扰）；
3. 对策：混频前加高Q输入回路（抑镜像）、或提高中频（镜像离得更远）、二次变频。

### 例题 6：为什么 FM 收音机加 AFC？

**题目**：本振漂移 10kHz，FM 中频 10.7MHz，影响？

**详解**：中频偏 10kHz → 鉴频器工作点偏移 → 失真+噪声。AFC（自动频率控制）用鉴频输出电压回拉本振变容二极管 → 稳频。现代实现则是整环数字锁相（DDS/PLL 频率合成）。

## 六、调制解调电路

- **变容二极管调频**：u(t) 改变结电容 → 直接拽振荡器频率（无线话筒）；
- **包络检波**：二极管+RC 充放电跟包络（AM 收音机，便宜大碗；条件 RC 满足 1/ω_c ≪ RC ≪ 1/ω_m，避免对角切割失真）；
- **鉴频**：先将等幅 FM 变成调幅调频波（斜率/相位鉴频），再包络检波。

### 例题 7：包络检波元件选取

**题目**：载频 465kHz，音频 3kHz。检波 RC 取多少？

**详解**：需 1/ω_c ≪ RC ≪ 1/ω_m → RC 介于 0.34μs 与 53μs → 取 **RC ≈ 5~10μs**（如 4.7kΩ + 2200pF ≈ 10μs）。

## 七、锁相环 PLL（高频系统的"瑞士军刀"）

结构：鉴相器(PD) + 环路滤波器(LF) + 压控振荡器(VCO) 闭环。

锁定后 f_out 跟随 f_in（相位差恒定）。用途：**频率合成**（f_out = N·f_ref，改变分频比 N 换频道）、载波同步、FM 解调（VCO 控制电压即解调输出）、时钟恢复。

### 例题 8：频率合成器

**题目**：基准晶振 10MHz，需要 900~1800MHz 步进 100kHz 的本振（GSM）。N 范围？

**详解**：
1. 参考 100kHz = 10MHz/100（参考分频 R=100）；
2. N = f_out/f_ref：N_min = 900M/100k = 9000，N_max = 1800M/100k = 18000；
3. 小数分频（ fractional-N）还能做到更细步进——手机射频芯片的核心模块就是它。

---

## 八、易错点清单

1. 振荡器"相位平衡"看的是**环路总相移**（含放大器反相），别只看反馈网络。
2. 丙类功放导通角越小效率越高，但输出功率会下降——不是越小越好。
3. 镜像频率是 f_LO+f_IF，与信号关于本振**对称**。
4. PLL 锁定后频差为零、**相位差恒定不为零**。
5. 变容二极管是**反偏**使用（利用结电容随电压变化）。
