# 信息论与编码

> 科目：通信工程 ｜ 收录日期：2026-08-17 ｜ 来源：知识123/通信工程知识库

> 信息论回答两个终极问题：①"信息"到底多少，怎么度量？②信道最多能传多少？香农 1948 年一篇论文创立的学科，是所有压缩算法（ZIP/H.265）和纠错码（5G LDPC）的理论之母。

## 二、信息的度量

### 2.1 自信息：越意外越有信息

$$I(x_i) = \log_2\frac{1}{P(x_i)} \ \text{bit}$$

- 必然事件 P=1 → I=0（没有信息量，废话）；
- 小概率事件 → 信息量大（"明天太阳升起"没信息，"中彩票"信息巨大）。

### 2.2 熵：平均不确定性

$$H(X) = -\sum_i P(x_i)\log_2 P(x_i) \ \text{bit/符号}$$

**性质**：等概率时最大 H = log₂n；概率越"偏"熵越小；确定事件 H=0。

### 例题 1：抛硬币的熵

**题目**：公平硬币的熵？偏到 P(正)=0.99 呢？

**详解**：
1. 公平：H = −(0.5log0.5+0.5log0.5) = **1 bit**（每次抛掷恰好 1 bit 信息）；
2. 偏硬币：H = −(0.99log₂0.99+0.01log₂0.01) ≈ 0.99×0.0145 + 0.01×6.64 ≈ **0.08 bit**（结果几乎注定，信息量骤减）。

### 例题 2：英语字母的熵（理解冗余）

**题目**：26 个字母等概率熵是多少？实际英语约 4.03 bit，说明什么？

**详解**：等概率 H = log₂26 ≈ **4.7 bit/字母**；实际 4.03 → 字母间相关性（q 后必跟 u 等）造成**冗余**。冗余约 1−4.03/4.7 ≈ 14%（考虑词级更高，约 50%+）——所以文本能被 ZIP 压缩：**压缩的本质就是去除冗余**。

### 2.3 条件熵与互信息

- H(X|Y)：收到 Y 后 X 还剩的不确定性；
- **互信息 I(X;Y) = H(X) − H(X|Y)**：收到 Y 平均消除的关于 X 的不确定性 = 传递的信息量。

## 三、信源编码（压缩）

**香农第一定理（无失真信源编码）**：无失真编码平均码长可以逼近熵 H，但绝不能小于 H——**熵是压缩的极限**。

### 3.2 霍夫曼编码（必考手工题）

**步骤**：①概率排序；②合并两个最小概率为新节点反复向上建树；③树上左0右1读码。

### 例题 3：霍夫曼编码全过程

**题目**：信源 P = {a:0.4, b:0.2, c:0.2, d:0.1, e:0.1}。构造霍夫曼码并求平均码长与效率。

**详解**：
1. 合并最小：d(0.1)+e(0.1)=0.2；再 c(0.2)+de(0.2)... 逐层合并建树，得编码（之一）：
   a=1, b=010, c=011, d=0000, e=0001（不唯一，码长集合唯一）
2. 平均码长 L̄ = 0.4×1 + 0.2×3 + 0.2×3 + 0.1×4 + 0.1×4 = **2.2 bit/符号**；
3. 熵 H = −(0.4log0.4+2×0.2log0.2+2×0.1log0.1) ≈ 2.122 bit；
4. 效率 η = H/L̄ ≈ **96.5%**，逼近香农极限。
> 前缀码性质：任何码字不是其他码字的前缀 → 收流可直接切分（变长码不需要分隔符）。

### 例题 4：为什么能预测就省流量？

**题目**：视频相邻帧几乎相同，H(帧ₜ|帧ₜ₋₁) ≪ H(帧ₜ) 说明什么？

**详解**：条件熵远小于边际熵 → 传"差值"（运动补偿+残差）所需比特远小于传整帧——**H.264/H.265 视频压缩的核心**。手机看视频每秒只需几十 kbit 却能播 1080p，全是信息论的功劳。

## 四、信道容量

### 4.1 互信息最大化

$$C = \max_{P(x)} I(X;Y)$$

**香农第二定理（信道编码定理）**：只要传信率 R < C，必存在编码方式使误码率任意小；R > C 则不可能可靠传输。**它是 5G LDPC/Turbo 码能逼近极限的法理依据。**

### 例题 5：BSC 信道的容量（二元对称信道）

**题目**：BSC 误码率 p=0.01（发0收1或反之）。信道容量？

**详解**：
1. C = 1 − H(p)，H(0.01) = −(0.01log0.01+0.99log0.99) ≈ 0.0808 bit；
2. C ≈ 1 − 0.081 = **0.919 bit/符号**（最多传 91.9% 的信息）。
3. 特例：p=0.5 → C=0（信道完全废掉，输出与输入无关）；p>0.5 反而能"反着用"恢复信息。

### 例题 6：连续信道（AWGN）—— 香农公式再现

**题目**：带宽 1MHz，SNR=20dB，容量？

**详解**：20dB→100 倍；C = 10⁶·log₂101 ≈ **6.66 Mbit/s**。扩频（CDMA）、单载波 vs OFDM 的各种"频谱策略"，都是在 C 的约束下做文章。

### 例题 7：信道容量怎么选输入分布？

**题目**：二进制输入、输出连续的 AWGN 信道在低 SNR 时什么输入最好？

**详解**：低信噪比时 BPSK 输入已接近高斯输入的容量（"积少成多"策略）；高 SNR 时需要高阶星座（256QAM）逼近容量——**这正是 WiFi/5G 自适应调制的理论依据**（对照通信原理图11）。

## 五、率失真理论（有损压缩）

**率失真函数 R(D)**：失真不超过 D 所需的最小码率。D→0 时 R(D)→H（无损极限）；允许失真，码率可大幅下降。

**应用链**：语音 CELP（码本激励，8kbit/s 打电话）→ JPEG（DCT+量化+霍夫曼）→ AAC/Opus 音频 → AI 时代的神经压缩。本质都是"在可感知范围内买失真换带宽"。

### 例题 8：量化的失真-码率权衡

**题目**：高斯信源方差σ²，n bit 均匀量化的率失真关系？

**详解**：R(D) = ½log₂(σ²/D)。n bit → D ≈ σ²·2^(−2n)：**每加 1bit，失真降 4 倍（6dB）**——与数电的"6dB规则"和 SQNR 公式完全同源。

## 六、信道编码进阶（衔接通信原理）

| 码 | 结构 | 特点与应用 |
|---|---|---|
| 汉明码 (7,4) | 线性分组 | 纠1位错，内存ECC |
| BCH/RS | 多位纠错 | 深空、CD/DVD、QR码 |
| 卷积码+Viterbi | 流式，记忆 | GSM、卫星 |
| Turbo | 并行级联+迭代 | 3G/4G，首次逼近香农限(0.5dB) |
| **LDPC** | 稀疏校验矩阵 | DVB-S2、5G 数据信道，性能王 |
| **Polar** | 极化变换 | 5G 控制信道，首个"被证明达到容量"的码 |

### 例题 9：编码增益（花带宽买功率）

**题目**：未编码 BPSK 在 BER=10⁻⁵ 需 Eb/N0≈9.6dB；加 (2,1,7) 卷积码硬判决后 4.2dB。增益？

**详解**：增益 = 9.6−4.2 = **5.4dB**——同样误码率发射功率只需 1/3.5；代价是码率 ½（带宽翻倍）。深空通信（旅行者号起）全是这一交换的信徒。

## 七、易错点清单

1. 熵的单位取决于对数底：log₂→bit，ln→nat，log₁₀→Hart。
2. 霍夫曼编码不唯一，但**平均码长唯一**；必须验证前缀条件。
3. 香农公式是**上限**（存在性定理），没告诉你怎么造码——工程上靠 LDPC 等逼近。
4. 互信息对称：I(X;Y)=I(Y;X)，别当成"单向信息"。
5. "信息"≠"消息长度"：1MB 的全 0 文件信息量≈0。
