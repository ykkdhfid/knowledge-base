# 魔法少女伊莉雅

> 科目：小说漫画 ｜ 类型：设定梳理（用自己的话整理，非原文搬运）

全名《Fate/kaleid liner 魔法少女☆伊莉雅》，是 Fate 系列的**魔法少女题材衍生外传**，与本篇是平行世界关系。

## 是什么

- 以本篇角色「伊莉雅」（Illyasviel von Einzbern）为主角的魔法少女故事；
- 作者：广山弘（ひろやまひろし）；
- 从 Fate/stay night 的设定出发，走了完全不同的一条轻松路线（前期偏日常搞笑，后期渐入主线）。

## 与 Fate 本篇的关系

- 角色沿用 Fate 的人设（伊莉雅、美游等），但世界线独立；
- 不需要先看完本篇也能入坑，但如果看过 Fate/stay night 和 Fate/Zero 会更懂彩蛋。

## 正版入口

- 动画：bilibili（共多季，SILVER LINK 制作）
- 漫画：哔哩漫画
