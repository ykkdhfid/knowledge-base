# Fate系列与圣杯战争设定

> 科目：小说漫画 ｜ 类型：设定梳理（用自己的话整理，非原文搬运）

Fate 是日本 TYPE-MOON 出品的系列作品，核心设定围绕「圣杯战争」展开。

## 圣杯战争是什么

一场由 7 位魔术师（御主 / Master）各自召唤 1 名英灵（从者 / Servant）组成的争夺战。7 组人互相厮杀，最后存活的一组能获得「圣杯」——一个据说能实现任何愿望的万能许愿机。

## 关键概念

| 概念 | 说明 |
| --- | --- |
| 御主（Master） | 参战的魔术师，为从者提供魔力 |
| 从者（Servant） | 历史上或传说中的英雄死后化为的英灵，被召唤到现世 |
| 令咒 | 御主对从者的 3 次强制命令权，用完即失效 |
| 圣杯 | 争夺的目标，能实现愿望 |

## 七大基础职阶

1. Saber（剑士）
2. Archer（弓兵）
3. Lancer（枪兵）
4. Rider（骑兵）
5. Caster（魔术师）
6. Assassin（暗杀者）
7. Berserker（狂战士）

## 主要作品

- **Fate/stay night**（2004）—— 系列原点，三条故事线（Fate / UBW / HF）
- **Fate/Zero** —— 前传，讲述第四次圣杯战争
- **Fate/Grand Order** —— 手游，规模最大、英灵最多的作品
- **魔法少女伊莉雅** —— 魔法少女题材的衍生外传

## 正版入口

- 动画：bilibili（Fate/Zero、Fate/stay night 各线动画）
- 漫画/小说：哔哩漫画、台版（尖端出版、角川）
- 手游：Fate/Grand Order（国服）
