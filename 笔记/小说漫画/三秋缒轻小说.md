# 三秋缒轻小说

> 科目：小说漫画 ｜ 类型：作者与作品简介（用自己的话整理，非原文搬运）

三秋缒（みあき しがる）是日本轻小说作家，作品以略带忧伤、温柔治愈的笔调著称，篇幅都不长，很适合一口气读完。

## 主要作品

| 作品 | 一句话印象 |
| --- | --- |
| 重启人生 | 关于「如果人生能重来」的温柔故事 |
| 三日间的幸福 | 用「剩余寿命」换钱的设定，探讨幸福 |
| 恋爱寄生虫 | 以「寄生虫」比喻恋爱关系 |
| 那年夏天（上/下） | 一通打给过去的电话引发的青春故事 |
| 不哭不哭 | 治愈系短篇集 |
