# 书架网站 —— 在 PyCharm 中运行（手把手版）

## 这个网站是什么？
一个**只在你自己电脑上运行**的书架：现共 **31 本**——4 部古典名著公版全文、3 部原创轻小说、奈须蘑菇与三秋缒两位作家的作品导读、通信工程知识库、毕业论文指南。支持分类、搜索、字号调节、记住阅读进度、深色模式。

## 运行步骤（照做就行）

### 第 1 步：用 PyCharm 打开项目
PyCharm → File → Open → 选择 `E:\知识123\书架网站` 文件夹 → OK。

### 第 2 步：配置 Python 解释器（只做一次）
- File → Settings → Project: 书架网站 → Python Interpreter；
- 右上齿轮 → Add → Local Interpreter → 选 **Virtualenv**（默认即可）→ OK；
- 等 PyCharm 生成完 `.venv` 文件夹。

### 第 3 步：安装依赖
- 打开 PyCharm 底部的 **Terminal**（终端）标签；
- 输入下面的命令并回车（等它跑完）：
```
pip install flask markdown
```

### 第 4 步：启动！
- 在左侧文件树里找到 `app.py` → 右键 → **Run 'app'**；
- 看到下面这行字就成功了：
```
书架已启动，浏览器打开 http://127.0.0.1:5000
```
- PyCharm 会自动弹出浏览器；没弹的话，手动打开浏览器访问 **http://127.0.0.1:5000**。

### 第 5 步：停止 / 重启
- 停止：点 PyCharm 运行窗口里的红色方块 ■；
- 重启：再右键 Run 即可（代码改动会自动生效）。

## 常见问题

| 问题 | 解决办法 |
|---|---|
| 打不开网页 | 确认终端里有 "Running on http://127.0.0.1:5000"；浏览器别开代理 |
| 提示 ModuleNotFoundError: flask | 回到第 3 步重新 pip install（注意是在 PyCharm 的 Terminal 里装，不是系统 cmd） |
| 端口被占用 | 把 `app.py` 最后一行 `port=5000` 改成 `port=5001`，网址也改成 5001 |
| 知识库章节显示纯文本 | `pip install markdown` 后重启 |
| 图片不显示 | 说明知识库文件夹被移动了；保持 `E:\知识123` 整体结构不变即可 |

## 知识导图 ↔ 书架（已联动）
- 书架**顶栏**有「🗺️ 知识导图」按钮，一点即开导图；
- 导图里**带链接的节点**（01 数学基础 … 13 计算机网络、毕业论文实战、我的书架各分类）**点击即跳转到书架对应章节/分类**；
- 前提：书架网站正在运行（127.0.0.1:5000）。

## 想读奈须蘑菇的正文？
1. 通过正规渠道获取你自己的合法文本（正版电子书/实体书等）；
2. 把 txt 文件放进 `书库\奈须蘑菇\对应作品文件夹\`（段落之间空一行）；
3. 用记事本打开 `书库\books.json`，找到对应作品，在 `chapters` 里照抄一行格式、`file` 指向你的 txt；
4. 刷新网页，就能在书架里读自己的书了。

## 想加自己的书？
1. 在 `书库\轻小说\` 下新建文件夹（如 `我的小说\`），放入每章的 `.txt`（段落之间空一行）；
2. 用记事本打开 `书库\books.json`，仿照《星野频率》的格式加一段（id 起个英文名，cover 的渐变色可自选）；
3. 刷新网页即可看到新书。
