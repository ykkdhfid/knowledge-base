## 二、快速开始（三分钟上手）

1. **看知识**：双击 `知识导图\通信工程知识导图.html`（需联网加载组件）或查看 `知识导图\通信工程知识导图.png`（离线）。**书架网站运行时，导图里带链接的科目名点击即可直达书架对应章节**；然后进入 `通信工程知识库\` 按顺序学习（推荐用 Typora/Obsidian 打开 md 文件）。
2. **启动书架**：按 `书架网站\README_如何运行.md` 操作（PyCharm 打开 → pip install → 右键运行 app.py → 浏览器 127.0.0.1:5000）。
3. **开始毕设**：打开 `毕业论文\选题与实施指南.md`，第 0 步就是跑通代码。

## 四、四件套怎么串起来用（学习闭环）

```
① 上新课/复习 → 打开 知识导图 定位知识点 → 跳转对应学科讲义精读、做例题
② 想动手实验 → 改 make_figures.py 里的参数（如改载波频率/滚降系数）重新出图
③ 大四写论文 → 选题指南选好题 → 代码跑出结果图 → 图表对应讲义里的理论章节
④ 日常阅读  → 书架网站看轻小说放松，也能直接翻全部讲义复习
```

## 五、必读提醒

- **讲义图片显示**：md 文件用 Typora / Obsidian / VS Code 打开时插图自动显示；记事本看不了图。
- **轻小说为原创**：三部小说均为 AI 原创内容，无版权风险，可放心阅读、转发。
- **毕业论文诚信**：指南和代码是脚手架，论文请用自己的语言撰写，实验请亲手运行（详见指南第四节的提醒）。
- **保持目录结构**：书架网站通过相对路径引用知识库，请勿单独移动 `通信工程知识库` 文件夹。
