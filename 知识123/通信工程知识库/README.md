## 怎么用这份知识库

1. **预习/复习**：打开对应课程 markdown，先看"知识地图"建立框架，再逐节精读；
2. **例题演练**：先遮住"详解"自己算，再对答案；每章末尾有"易错点清单"，考前必看；
3. **图片理解**：所有波形图/星座图都可以用 `make_figures.py`（在 `E:\知识123\` 下）重新生成并修改参数做实验；
4. **串联复习**：配合 `E:\知识123\知识导图\通信工程知识导图.html` 交互式导图，从任意知识点跳转；
5. **毕业论文**：直接进入 `E:\知识123\毕业论文\选题与实施指南.md`，选题已在其中为你准备好。

## 查看工具推荐

- **Typora / Obsidian / VS Code（装 Markdown 预览插件）**：本地阅读体验最好，插图可直接显示；
- 也可以打开书架网站（`E:\知识123\书架网站`），在浏览器里阅读全部内容。
