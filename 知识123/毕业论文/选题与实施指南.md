### 第 6 步：答辩问题预测（提前背好）

1. **为什么你的仿真点和理论曲线不完全重合？** → 蒙特卡洛有限样本的统计涨落，BER 越低所需样本越多（按 10/BER 经验取比特数）；
2. **QPSK 为什么和 BPSK 的 BER 曲线重合？** → QPSK 每符号 2bit，I/Q 两路等效两个正交 BPSK，格雷映射下比特错误率相同，但频谱效率翻倍；
3. **瑞利信道为什么差这么多？** → 无直射径，多径相消造成深衰落，幅度服从瑞利分布，平均 BER 随 SNR 只按 1/γ 下降（AWGN 是指数下降）；
4. **Eb/N0 和 SNR 什么区别？** → Eb/N0 归一化到每比特能量，与调制阶数无关，才能公平比较不同调制；
5. **你的工作和别人有什么不同？** → 参数矩阵对比 + 分集改善量化 + Python 开源可复现。
