# 运行说明（PyCharm 版）

## 1. 用 PyCharm 打开
File → Open → 选择 `E:\知识123\毕业论文` 文件夹 → 以新窗口打开。

## 2. 配置解释器（第一次）
- File → Settings → Project → Python Interpreter；
- 若显示"No interpreter"，点右上齿轮 → Add → Local → 选 System Interpreter（Python 3.13）或新建 Virtualenv；
- 打开 PyCharm 底部 Terminal，执行：
  ```
  pip install numpy matplotlib
  ```

## 3. 运行
右键 `代码/communication_sim.py` → **Run 'communication_sim'**。
- 运行约 30~90 秒（取决于电脑）；
- 控制台实时打印每个信噪比点的 BER；
- 结束后 4 张论文图自动保存在 `毕业论文\结果图\`。

## 4. 常见问题
| 报错 | 解决 |
|---|---|
| ModuleNotFoundError: numpy | Terminal 里 `pip install numpy matplotlib` |
| 图中文显示为方框 | 你用的非 Windows 自带字体环境；把代码开头 'Microsoft YaHei' 换成 'SimHei' |
| matplotlib 弹出窗口卡住 | 已设 Agg 后台模式，正常不弹窗；若弹窗可忽略 |
| 想改实验参数 | 文件开头 `SEED`（随机种子）、`USE_DIVERSITY`（分集开关）；各函数内 `ebn0s` 范围 |

## 5. 改代码做"自己的实验"（论文加分项）
- 改 `ebn0s = np.arange(0, 13, 1.0)` 为 `np.arange(0, 20, 2.0)` 看更高信噪比；
- 把 `simulate_rayleigh_bpsk(..., n_branch=2)` 改成 3、4 支路，观察分集增益饱和；
- 在 main() 里仿照 16QAM 增加 64QAM（电平 ±1±3±5±7，能量归一化系数 √(6/42)）。
