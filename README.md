# 知识库（Knowledge Base）

我的个人知识库，用 [Obsidian](https://obsidian.md) 打开本文件夹即可浏览，笔记之间用 `[[文件名]]` 互链成网。

## 目录结构

| 文件 / 文件夹 | 说明 |
| --- | --- |
| `使用说明.md` | 建库规则（互链用 `[[文件名]]`；每收录一篇走「存原文→写笔记→更新目录→流水账」四步） |
| `目录.md` | 总目录：按科目列出所有笔记 |
| `流水账.md` | 每次收录的记录 |
| `笔记/` | 各科目的 Markdown 笔记 |
| `原文/` | 原始资料存档 |

## 科目

考研（政治 / 英语 / 数学 / 综合）、大学英语、计算机与网络、电子与电路、通信与信号、智能交通、网络安全、烹饪、公务员考试、小说漫画、插画图库等。
